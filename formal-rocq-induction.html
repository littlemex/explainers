この回の前提: 第 15 回 最初の証明: Theorem, rewrite, destruct

前回は intros ・ simpl ・ reflexivity ・ rewrite ・ destruct という道具を使い、1 つの式を証明しました。今回の主役は induction というタクティクです。これは第 05 回で見た「ドミノが全部倒れることを確かめる」帰納法を、Rocq の証明の中で実際に動かす道具です。手では確かめきれない「すべての自然数について」という主張を、機械に 1 歩ずつ確認させます。

1. なぜ simpl だけでは n + 0 = n が示せないか

Rocq の自然数の足し算 (plus) は、次のように最初の引数で場合分けして定義されています。

Fixpoint plus (n m : nat) : nat :=
  match n with
  | O => m
  | S n' => S (plus n' m)
  end.

ここでの nat は Rocq の標準のもので、構成子 (値を作る部品) は O (ゼロ) と S (次の数) の 2 つです。Rocq は O を数字の 0 と表示し、S (S O) を 2 と表示します。だから以下では 0 と O は同じものです。

この定義を使うと、0 + n = n はすぐに証明できます。最初の引数が具体的な O なので、match の 1 行目がそのまま選ばれ、式は n に計算できるからです。simpl がこの計算を進め、reflexivity (両辺が同じ形であることの確認) で終わります。

ところが n + 0 = n はそうはいきません。ここでの n は「ある決まった数」ではなく「どんな自然数でもよい、まだ分かっていない値」です。match n with ... は n が O なのか S n' なのか分からない限り、どちらの行を選ぶか決められません。だから simpl は計算を 1 歩も進められず、reflexivity も「両辺が同じ形」と確認できずに失敗します。

図: plus の場合分けの軸と一致する側はすぐ計算できるが、一致しない側は止まる。

2. induction n as [| n' IHn'] の構文

induction n as [| n' IHn'] は、第 05 回のドミノと同じ 2 つの作業を Rocq に指示します。1 つ目は n = O の場合 (最初のドミノ)、2 つ目は n = S n' の場合で、このとき「1 つ前の数 n' ではもう証明が終わっている」という帰納法の仮定 IHn' が自動で手に入ります (「このドミノが倒れたなら」の部分)。2 つの場合は - (ハイフン) で区切って、それぞれ別に証明します。

Theorem add_0_r : forall n : nat, n + 0 = n.
Proof.
  intros n. induction n as [| n' IHn'].
  - reflexivity.
  - simpl. rewrite -> IHn'. reflexivity.
Qed.

1 つ目の - は n = O の場合で、ゴールは 0 + 0 = 0 となり、具体的な数どうしの計算なので reflexivity だけで終わります。2 つ目の - は n = S n' の場合です。ゴールは S n' + 0 = S n' で、simpl によって S (n' + 0) = S n' まで進みます。ここで帰納法の仮定 IHn' : n' + 0 = n' を rewrite -> で使うと、ゴールの中の n' + 0 が n' に置き換わり、S n' = S n' となって reflexivity で閉じます。

図: induction が作る 2 つのゴールは、ドミノの「最初の 1 枚」と「n' から n'+1 への伝わり方」に対応する。

3. Qed が確かめているもの

タクティクを並べて証明を書いている間、Rocq は裏側で 1 つの証明の項 (この主張を実際に成り立たせる具体的な構成) を組み立てています。Qed はこの項を、タクティクの指示とは無関係に、型チェッカー自身がもう一度独立に検証するという意味を持ちます。つまり「このタクティクを信じてよいか」ではなく「組み立てられた証明そのものが本当に正しいか」を機械が確かめているのです。

この章の最初に見た「simpl. reflexivity. だけで n + 0 = n を済ませようとする」証明は、実際に試すとこの時点でエラーになり、最後の Qed まで到達できません。これは手抜きが見逃されたわけではなく、plus の定義が実際にどう計算するかに証明の進め方が従わなければならない、ということを示しています。式が「正しそうに見える」ことと、Rocq の計算規則に沿って「実際に計算が進む」ことは別の話であり、induction はその間を帰納法の仮定でつなぐ道具です。
