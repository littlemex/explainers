この回の前提: 第 07 回 システムを状態機械として見る

前回、状態・遷移・振る舞いという考え方を見ました。今回はそれを実際の TLA+ の記法で書きます。1 から 12 を繰り返すだけの小さな時計を例に、ファイルの骨組みと最初の仕様の書き方を覚えます。

1. ファイルの骨組み: MODULE・EXTENDS・VARIABLES

TLA+ の仕様ファイルは、決まった骨組みから始まります。先頭に ---- MODULE 名前 ---- と書き、名前はファイル名と一致させます。次に EXTENDS Naturals と書くと、自然数の足し算や比較が使えるようになります。そのあとに VARIABLES で、システムの状態を決める変数を宣言します。時計の例では、時刻を表す変数 hour が 1 つあれば十分です。

---- MODULE Clock ----
EXTENDS Naturals

VARIABLES hour

ファイルの最後は ==== (等号 4 個以上) で閉じます。この骨組みの中に、状態がどう変わるかを表す式を書き加えていきます。

MODULE の前後のハイフンと、末尾の等号は、どちらも「4 個以上」であれば構いません。短くても長くても TLA+ の構文としては同じ意味になります。EXTENDS は、他のモジュールで定義済みの演算子をまとめて取り込む宣言です。Naturals は TLA+ が標準で用意しているモジュールの 1 つで、自然数の足し算や大小比較、範囲を表す .. などの演算子が入っています。今回の時計の例では、hour + 1 という足し算と hour = 12 という比較を使うために EXTENDS Naturals が必要です。

2. Init と Next: プライム表記・/\・\/・UNCHANGED

初期状態を決める式を Init という名前で定義します。時計なら Init == hour = 1 とし、「初期状態では hour が 1 である」という意味になります。状態がどう変わるかは Next という名前で定義し、変数名にプライム (') を付けた次の状態での値と、プライムの付かない今の状態での値を比べる式で書きます。

Init == hour = 1

Next == hour' = IF hour = 12 THEN 1 ELSE hour + 1

hour' は次の状態での hour の値、hour は今の状態での値を指します。この 1 行は「hour が 12 なら次は 1、そうでなければ次は hour+1」という意味の等式で、TLA+ ではこの式全体が真か偽かを判定できる 1 つの命題として扱われます。複数の条件を同時に満たしたいときは /\ (かつ) で、どちらか一方でよいときは \/ (または) で並べます。変数の値をそのままにしたいときは UNCHANGED hour と書き、これは hour' = hour の略記です。複数の変数をまとめて変えないときは UNCHANGED <<x, y>> のように書けます。

Init と Next という名前自体に特別な力はありません。TLA+ では == を使って式に名前を付けられるだけで、Init も Next も単なる名前です。どの式を初期状態として使い、どの式を遷移として使うかは、この後で定義する Spec の中で、あるいは TLC に渡す設定ファイル (.cfg) の中で指示します。名前を自由に選べるからこそ、次回以降は TypeOK のような別の名前の式も同じ書き方で増やしていけます。

3. Spec == Init /\ [][Next]_vars

最後に、仕様全体を 1 つの式 Spec にまとめます。

Spec == Init /\ [][Next]_hour

[][Next]_hour は「常に、[Next]_hour が成り立つ」という意味で、[Next]_hour 自体は Next \/ UNCHANGED hour の略記です。つまり「毎回、Next の規則で hour が変わるか、もしくは hour が変わらずそのままか、どちらかが続く」という意味になります。「変わらなくてもよい」という選択肢を許しているのは、他の部品が動いている間はこの変数が止まっていてもよい、という並行システム向けの約束です。これで Clock モジュールの最初の仕様が完成しました。

ここまでの式を 1 つのファイルにまとめると、次のようになります。これが今回検査用に用意した Clock.tla の全文です。

---- MODULE Clock ----
EXTENDS Naturals

VARIABLES hour

Init == hour = 1

Next == hour' = IF hour = 12 THEN 1 ELSE hour + 1

Spec == Init /\ [][Next]_hour

====

この仕様はまだ「何を検査するか」を 1 つも決めていません。TLC に渡す設定ファイル (.cfg) には、今のところ SPECIFICATION Spec という 1 行だけを書き、どの式を仕様として使うかを指示します。次回は、常に成り立つべき条件 (不変条件) を書き加え、それを TLC に検査させる方法を見ます。
