DeltaNet / Gated DeltaNet — delta 則で状態を直す

固定状態への「加算」は古い記憶を壊す。だから誤差だけを見て直す

0この章の狙い

この記事は Attention の基礎、そして前章 Linear Attention の固定状態 $S_t$ による再帰更新を前提にします。まだの方は先に Softmax Attention をビジュアルに理解する と 前章: Linear Attention — softmax を外して O(N) に を読んでください。

一言でいうと
前章の Linear Attention は、状態 $S_t$ に $\phi(k_t)v_t^\top$ を無条件に足し込むだけでした。似たキーが繰り返し来ると値が上書きされ続け、状態が飽和して古い連想が壊れます。DeltaNet は、この加算を「予測してから、誤差の分だけ直す」delta 則 (Widrow–Hoff の最小二乗則) に置き換えます。さらに Gated DeltaNet は、トークンごとに入力から決まる (時間方向に選択的な) 忘却ゲート $g_t$ (Mamba-2 由来) を状態の全チャネルに一律に掛けて減衰させ、delta 則と組み合わせます。固定状態という土台は変えず、「何を・どれだけ書き込むか」を精緻化するのがこの章です。
1. 何を解決する手法か 2. 数式で見る DeltaNet / Gated DeltaNet 3. 計算量 4. 【構成】加法更新 vs delta 更新 5. 【体験】書き込み強度と忘却ゲートを動かす 6. 代表モデルと系統上の位置 7. まとめ

1何を解決する手法か

固定状態は有限容量の連想記憶。無条件に加算し続けると、いずれ壊れる。

前章の Linear Attention は、状態 $S_t$ を「キーが来たら値を足す」という単純な累積更新 $S_t = S_{t-1} + \phi(k_t)v_t^\top$ で更新していました。$S$ を「キーを入れると値を返す」線形連想記憶とみなすと、これは常に無条件で書き込む操作です。しかし、似たキーが繰り返し来ると、そのたびに値が無条件に足し込まれ、状態が飽和して古い連想が壊れていきます。固定サイズの状態は、書き続ければ古い記述が上書きされる容量固定のホワイトボードのようなもので、この飽和は避けられません。

ここで問われる着想はシンプルです。今の状態がすでに知っている分は書き直さず、知らない分 (誤差) だけを書き込めばいい。状態 $S_{t-1}$ を連想記憶とみなすと、キー $k_t$ に対する現在の予測値は $\hat v_t = S_{t-1}^\top k_t$ と読み出せます。新しい値 $v_t$ との予測誤差 $v_t - \hat v_t$ だけを、書き込み強度 $\beta_t$ でキー方向に足す ― これが Schlag らの arXiv:2102.11174 "Linear Transformers Are Secretly Fast Weight Programmers" が持ち込んだ、Widrow–Hoff の古典的な delta 則 (least mean squares) です。単なる加算が「無条件に足す」のに対し、delta 則は「必要な差分だけ足す」ので、有限容量の状態を効率よく使えます。

もう一つの課題は並列化です。delta 則の更新は各ステップで $(I-\beta_t k_t k_t^\top)$ という行列が左から挟まる形になり、加算更新のような単純な累積和には畳めません。これを chunk 単位の行列演算に展開して GPU で並列化する道を開いたのが arXiv:2406.06484 "Parallelizing Linear Transformers with the Delta Rule over Sequence Length" で、DeltaNet が実モデルのスケールに乗る転機になりました。さらに arXiv:2412.06464 Gated Delta Networks は、状態を一律に減衰させる忘却ゲート $g_t \in (0,1)$ を掛け、Mamba-2 流の選択的忘却と delta 則を統合しました。

着想を1行で。 「加算更新」→「予測して、誤差だけ直す (delta 則)」→「さらに忘却ゲートで状態全体を減衰させる (Gated DeltaNet)」。固定状態という前章からの土台は変えず、書き込み方だけを精緻化していく流れがこの章です。

2数式で見る DeltaNet / Gated DeltaNet

状態 $S_{t-1}$ からの予測値と実際の値 $v_t$ の差 (delta) だけを書き込みます。記号は本シリーズ共通のものを使います。

状態 $S_{t-1}$ を線形連想記憶とみなすと、キー $k_t$ に対する現在の予測値はこう読み出せます。

$$ \hat v_t = S_{t-1}^\top k_t $$

なお、前章の Linear Attention はキーにカーネル特徴写像 $\phi(k_t)$ を適用していましたが、現代の DeltaNet (Yang et al. 2024, arXiv:2406.06484) では $\phi$ を使わず、キー $k_t$ を L2 正規化 ($\lVert k_t\rVert=1$) してそのまま使います。$\beta_t\in(0,1)$ のとき $(I-\beta_t k_t k_t^\top)$ の固有値は $(0,1]$ に収まり、状態のノルムが発散しません。

新しい値 $v_t$ との予測誤差 $v_t - \hat v_t$ を、書き込み強度 $\beta_t$ でキー方向に足し込むのが DeltaNet の状態更新です。

$$ S_t = S_{t-1} + \beta_t\, k_t\,(v_t - \hat v_t)^\top = \big(I - \beta_t\, k_t k_t^\top\big)\,S_{t-1} + \beta_t\, k_t v_t^\top $$
# v_hat_t は状態からの読み出し (予測値)
v_hat_t = S_{t-1}^T k_t
# 予測誤差の分だけ書き込む (delta 則)
S_t = S_{t-1} + beta_t * k_t * (v_t - v_hat_t)^T

この更新は、二乗誤差 $\mathcal{L}_t = \frac{1}{2}\lVert S^\top k_t - v_t \rVert^2$ を状態について 1 ステップ勾配降下したもの ($S_t = S_{t-1} - \beta_t \nabla_S \mathcal{L}_t$) にちょうど一致します。$\beta_t$ は入力からトークンごとに学習される学習率で、実装では sigmoid を通して $(0,1)$ に収めることが多く、大きく取れば $k_t$ 方向の既存成分を強く消してから上書きし、小さく取れば緩やかに混ぜます。

Gated DeltaNet は、この更新にトークンごとに入力から決まる忘却ゲート $g_t \in (0,1)$ (Mamba-2 由来) を掛けます。$g_t$ は時間方向には選択的 (トークンごとに値が変わる) ですが、チャネル方向には一律 (スカラーとして状態の全チャネルに同じ値を掛ける) です。

$$ S_t = g_t\big(I - \beta_t\, k_t k_t^\top\big)\,S_{t-1} + \beta_t\, k_t v_t^\top $$
$\beta_t$ は「この差分をどれだけ強く書き込むか」、$g_t$ は「今までの状態全体をどれだけ残すか」という別の役割です。$g_t=1$ とすれば DeltaNet に一致するので、Gated DeltaNet は DeltaNet を包含する拡張になっています。後の章で扱う KDA では、この $g_t$ をさらにチャネルごとの対角ゲートへ細粒度化します。

状態からの出力 (読み出し) は、前章までと同じくクエリ $q_t$ で行います。

$$ o_t = S_t^\top q_t $$

3計算量

状態が固定サイズという前章からの性質は変わりません。delta 則そのもののコストは、chunk 化アルゴリズムで並列に吸収されます。

時間計算量 (prefill / 学習時)

delta 則の更新は各ステップで $(I-\beta_t k_t k_t^\top)$ が左から挟まるため、単純な累積和には畳めず素朴には系列方向に逐次的です。arXiv:2406.06484 の chunk 化アルゴリズムは、これを chunk 単位の行列演算に展開して GPU 上で並列に処理し、系列長 $N$ に対して$O(N)$ の chunk 並列で計算できるようにしました。$N^2$ のスコア行列は作りません。

Decode 時のボトルネック

前章と同じく、1 トークンを生成するのに必要なのは直前の状態 $S_{t-1}$ だけです。予測 $\hat v_t = S_{t-1}^\top k_t$ を計算し、誤差の分だけ状態を更新してから $o_t = S_t^\top q_t$ で読み出せば完結するため、KV-Cache のように過去 $N$ 件を読み直す必要はありません。

KV / 状態メモリの $N$ 依存

状態 $S_t$ は前章と同じ固定サイズで、系列長 $N$ には依存しません。delta 則と忘却ゲートは「固定容量をどう使うか」を精緻化するものであり、状態のサイズそのものを変える仕組みではありません。

O(N)時間計算量 (chunk 並列)
固定状態サイズ (N 非依存)
誤差分だけ書き込み量 (delta 則)

4【構成】加法更新 vs delta 更新

左は前章の加法更新 (無条件に足し込む)、右は DeltaNet の delta 更新 (予測して誤差だけ直す) です。トグルで切り替えてください。

キー $k_t$ 値 $v_t$ / 状態 $S$ 予測誤差 (delta) / 飽和する列 (加法)

加法更新に切り替えると、似たキーが来るたびに状態のマス目が無条件に濃く塗り重ねられ、やがて飽和 (衝突) することが分かります。delta 更新に切り替えると、まず現在の状態から予測値を読み出し、実際の値との誤差だけを計算し、その差分だけを状態に書き込む 3 ステップが流れます。同じキーが繰り返し来ても、すでに予測できている分は書き直さないため、状態が無駄に飽和しません。

5【体験】書き込み強度と忘却ゲートを動かす

書き込み強度 $\beta_t$ と忘却ゲート $g_t$ を動かして、簡単な数値例で連想記憶 $S$ (ここでは 1 つのスカラー成分として単純化) が誤差修正と減衰でどう変化するかを見ます。

書き込み強度 $\beta_t$
忘却ゲート $g_t$
0.50$\beta_t$
1.00$g_t$

この例では、目標値 $v=1.0$ に対して状態が毎ステップ $\hat v_t = S_{t-1}$ を予測し、誤差 $v-\hat v_t$ を $\beta_t$倍だけ足し込み、その前に $g_t$ 倍だけ状態を減衰させます。$\beta_t$ を大きくすると数ステップで目標値に近づくのが速くなり (収束が速い)、小さくすると緩やかに混ざります。$g_t$ を 1 未満に下げると、書き込みがなくても状態が徐々に減衰していく様子が見えます。DeltaNet は $g_t=1$ 固定、Gated DeltaNet は $g_t$ を学習してこの減衰を選択的に使います。

6代表モデルと系統上の位置

DeltaNet は Linear Attention の子で、Gated DeltaNet はその直接の拡張です。

DeltaNet の理論的な骨格は Schlag et al. "Linear Transformers Are Secretly Fast Weight Programmers" (arXiv:2102.11174, 2021-02) が示しました。線形 Attention の fast weight 更新に Widrow–Hoff の delta 則を持ち込み、状態を連想記憶としてオンライン学習する更新に置き換えたものです。この更新を系列方向に並列化し、実モデルのスケールに乗せたのが Yang et al. "Parallelizing Linear Transformers with the Delta Rule over Sequence Length" (arXiv:2406.06484, 2024-06) で、論文では 1.3B パラメータ規模のモデルで検証されています。

Gated DeltaNet は Yang et al. "Gated Delta Networks: Improving Mamba2 with Delta Rule" (arXiv:2412.06464, 2024-12) で提案され、Mamba-2 由来の忘却ゲート $g_t$ を delta 則に統合しました。実運用の例としては、Qwen3-Next が Gated DeltaNet 層と Gated Attention 層を 3:1 で交互配置し、さらに MoE を組み合わせるハイブリッド構成を採用しています。

系統上の位置。 親は前章の Linear Attention です。加法更新を delta 則に置き換えるという最小限の変更で、固定状態という土台はそのまま引き継ぎます。delta 則の着想自体は 2021 年に遡りますが、RetNet・GLA などが確立した chunk 並列のハードウェア効率化技術の上で、2024 年に実用化されました。そこから Gated DeltaNet、さらに後の章で扱う KDA (忘却ゲートをチャネルごとの対角ゲートへ細粒度化) へと続きます。次章では系統をもう一本、Linear Attention と同じ「固定状態の再帰」という骨格を別の理論 (選択的状態空間モデル) から導いた Mamba / Mamba2 を見ます。

delta 則自体にも派生が続いています。Grazzi et al. (arXiv:2411.12537) は $\beta_t$ の値域を $(0,2)$ まで広げ、$(I-\beta_t k_t k_t^\top)$ の固有値を負の領域まで許すことで、偶奇判定 (parity) や置換の合成のような状態追跡タスクを解く能力を高めています。RWKV-7 も同様に一般化した delta 則を採用しており、さらに複数ステップの Householder 積へ拡張する DeltaProduct (Siems et al., 2025) といった発展も続いています。

7まとめ

論点要点
やること状態からの予測値 $\hat v_t=S_{t-1}^\top k_t$ と実際の値の誤差だけを、書き込み強度 $\beta_t$ で書き込む (delta 則)
数式$S_t=(I-\beta_t k_t k_t^\top)S_{t-1}+\beta_t k_t v_t^\top$。Gated 版は忘却ゲート $g_t$ を状態全体に掛ける。読み出しは $o_t=S_t^\top q_t$
時間計算量$O(N)$。chunk 化アルゴリズムで GPU 上を並列に処理
状態 / メモリ前章と同じ固定サイズ。$N$ に依存しない
代表モデルDeltaNet (理論・並列化の論文モデル)、Gated DeltaNet (論文)。実運用例: Qwen3-Next のハイブリッド構成
結論。DeltaNet は、固定状態への書き込みを「無条件の加算」から「予測誤差だけを直す delta 則」に置き換え、有限容量の状態をより効率よく使えるようにしました。Gated DeltaNet はさらに、Mamba-2 由来の忘却ゲートで状態全体を選択的に減衰させ、delta 則と忘却を統合します。固定状態という Linear Attention からの土台は変えず、「何を書き込み、何を残すか」を精緻化するのがこの章の一手でした。次章は同じ「固定状態の再帰」という骨格を、選択的状態空間モデルという別の理論から導いた Mamba / Mamba2 へ進みます。
