KDA — Kimi Delta Attention

Gated DeltaNet の忘却ゲートを、もっと細かい粒度に割る

0この章の狙い

この記事は Attention の基礎、そして前章 DeltaNet / Gated DeltaNet の delta 則と忘却ゲートを前提にします。まだの方は先に Softmax Attention をビジュアルに理解する と DeltaNet / Gated DeltaNet — delta 則で状態を直す を読んでください。

一言でいうと
KDA (Kimi Delta Attention) は、Gated DeltaNet の忘却ゲート $g_t$ を「1 ステップ 1 スカラー」から「状態の成分ごとに独立な対角ゲート」へ細粒度化した手法です。状態行列の各チャネルが自分のペースで忘れられるようになり、線形 Attention の固定状態という制約の中で、忘却の表現力を一段上げます。chunk 化アルゴリズムで並列化され、KV-Cache を要らない状態固定の系譜に連なりながら、Kimi Linear のような MLA とのレイヤー毎ハイブリッド構成で実運用に持ち込まれています。

1何を解決する手法か

Gated DeltaNet の忘却ゲート $g_t$ は 1 つのスカラーで、状態行列 $S_{t-1}$ 全体に一律に掛かります。

前章で見た Gated DeltaNet は、DeltaNet の delta 則更新に Mamba-2 流の忘却ゲート $g_t \in (0,1)$ を掛けて、状態を毎ステップ一律に減衰させました。$S_t = g_t\big(I - \beta_t k_t k_t^\top\big)S_{t-1} + \beta_t k_t v_t^\top$ という更新式で、$g_t$ はスカラーです。つまり状態行列のどの成分 (どのチャネル) も同じ速さで忘れられます。

しかし状態行列の各チャネルが担っている「記憶の種類」は本来均質ではありません。ある成分は長く保持したい情報を、別の成分は短命でよい情報を持っているかもしれない。忘却の速さを 1 つのスカラーに縛ると、この違いを表現できません。KDA は、この忘却ゲートをスカラーからチャネルごとに独立な対角ゲートへ細粒度化することで、状態容量の使い方に自由度を与えます。

KDA の着想は単純です。「忘却の速さも、状態の成分ごとに学習させればいい」。Gated DeltaNet が状態全体に 1 つの忘却率を掛けていたところを、対角行列 (チャネルごとに異なる値) に置き換えます。delta 則による誤差修正の骨格はそのまま引き継ぎ、忘却ゲートだけを精緻化するという、前章からの最小限かつ的を絞った拡張です。

2数式で見る KDA

Gated DeltaNet の更新式から、忘却ゲート $g_t$ をスカラーから対角行列 $G_t$ に置き換えるだけです。記号は本シリーズ共通のものを使います。

前章の Gated DeltaNet の状態更新はこうでした。

$$ S_t = g_t\big(I - \beta_t\, k_t k_t^\top\big)\,S_{t-1} + \beta_t\, k_t v_t^\top $$

KDA はここで、スカラーの $g_t$ を、状態の各チャネルに独立な値を持つ対角行列 $G_t = \mathrm{diag}(g_t^{(1)},\dots,g_t^{(d)})$ に置き換えます。概念的にはこう書けます。

$$ S_t = G_t\big(I - \beta_t\, k_t k_t^\top\big)\,S_{t-1} + \beta_t\, k_t v_t^\top $$
# G_t は対角行列 (チャネルごとに独立な忘却率)
G_t = diag(g_t^(1), g_t^(2), ..., g_t^(d)),   各 g_t^(i) ∈ (0,1)

$G_t$ が状態行列 $S_{t-1}$ に左から掛かる (行方向、つまり出力側チャネルごと) ため、各行が自分専用の忘却率で減衰します。$G_t$ が単位行列にスカラーを掛けたものに退化すれば Gated DeltaNet と一致するので、KDA は Gated DeltaNet を包含する拡張です。

ヘッジ。ここに示したのは Gated DeltaNet の枠組みに対角ゲートを当てはめた概念式で、KDA 論文 (Kimi Linear, arXiv:2510.26692) 固有の chunk 化アルゴリズムの詳細な行列展開は、本稿が参照している原文の範囲では確認できていません。「対角ゲートへの細粒度化」という骨格は原文に明記されていますが、具体的な chunk 内演算の式は捏造せず、ここでは骨格のみを示しています。

この対角ゲートは、DPLR (Diagonal-Plus-Low-Rank、対角+低ランク) と呼ばれる構造の一部を成します。delta 則の $(I - \beta_t k_t k_t^\top)$ の項自体が「単位行列 (対角) から低ランクの外積を引く」という DPLR 的な形をしており、KDA はこれに対角ゲート $G_t$ をさらに組み合わせることで、表現力を保ったまま chunk 単位の行列演算に展開できる構造を維持しています。

3計算量

DeltaNet 系と同じく、状態は固定サイズ・系列長に依存しません。対角ゲートへの細粒度化は表現力を上げる一方、演算コストの骨格は変えません。

時間計算量 (学習 / Prefill)

DPLR 構造専用の chunk 化アルゴリズムにより、系列長 $N$ に対して$O(N)$ の chunk 並列で計算できます。DeltaNet / Gated DeltaNet と同じく、chunk 単位に行列演算へ展開することで GPU 上で並列に処理でき、$N^2$ のスコア行列を作らずに済みます。

Decode 時のボトルネック

状態 $S_t$ は $d\times d$級の固定サイズで、過去の系列長 $N$ に依存しません。1 トークン生成ごとに読み直す量は状態サイズだけで、KV-Cache のように $N$ に比例して膨らみません。忘却ゲートが対角化された分、状態の情報保持の精度は上がりますが、状態のサイズそのものは変わらないため、decode のメモリ読み出し量は増えません。

KV / 状態メモリの $N$ 依存

固定状態のため $N$ 依存が消えます。原文では、KDA を含む Kimi Linear のようなハイブリッド構成で KV-Cache を最大 75% 削減、1M 文脈で decode スループットを最大 6 倍にしたと報告されています ([報告]。ハイブリッド構成全体での数値であり、KDA 単体の寄与を分離した数値ではない点に注意してください)。

O(N)時間計算量 (chunk 並列)
固定状態サイズ (N 非依存)
最大75%減 / 最大6倍KV削減 / 1M文脈decode (報告値)
KDA の計算量の骨格は前章 Gated DeltaNet と同じ「chunk 並列 $O(N)$、状態固定」です。対角ゲートへの細粒度化はこの骨格を保ったまま、忘却の表現力だけを上げる拡張だと理解してください。

4【構成】細粒度ゲートとハイブリッド配置

左側は Gated DeltaNet (スカラーゲート) と KDA (対角ゲート) の状態更新の違い。右側は Kimi Linear のような MLA とのレイヤー毎ハイブリッド構造です。

KDA (線形, 状態固定) MLA (全結合, KV潜在) 忘却ゲート成分

左図では、Gated DeltaNet の状態がすべてのチャネルで同じ速さで薄くなっていくのに対し、KDA では各チャネルが自分のゲート値で独立に減衰します。右図は、Kimi Linear が採用するような構成 ― KDA 層を主体に、一定周期で MLA (全結合 Attention) の層を挟むレイヤー毎ハイブリッドです。線形層で状態を定数に保ちながら、全結合層で厳密な長距離参照を補うという役割分担です。

5代表モデルと系統上の位置

KDA は Gated DeltaNet の直接の子で、Kimi Linear の中核に採用されています。

KDA (Kimi Delta Attention) は Kimi Team の論文 "Kimi Linear: An Expressive, Efficient Attention Architecture" (arXiv:2510.26692, 2025-10) で提案されました。Gated DeltaNet の忘却ゲートをスカラーからチャネルごとに独立な対角ゲートへ細粒度化し、DPLR 構造専用の chunk 化アルゴリズムで効率的に計算します。代表モデルは Kimi Linear です。

ヘッジ (重要)。2026 年後半の Kimi K3 は公式 blog で、線形の KDA と全結合系の Gated MLA を 3 対 1 の比率でレイヤー毎に交互に積むハイブリッド構成を採用していると述べています ([報告])。ただし本稿執筆時点で K3 の技術レポート・重みは未公開であり、K3 が採用する「KDA」が本章で扱う KDA (arXiv:2510.26692, Kimi Linear) と厳密に同一の実装かどうかの一次資料での確認はできていません。本章の代表モデルは、一次情報 (arXiv 論文) が確認できる Kimi Linear とします。K3 との対応は断定せず、参考情報として扱ってください。
系統上の位置差分
親: Gated DeltaNet忘却ゲートはスカラー $g_t$、状態全体に一律の減衰
本章: KDA忘却ゲートを対角行列 $G_t$ へ細粒度化、DPLR chunk 化アルゴリズムで効率化
実運用: Kimi LinearKDA を主体に、MLA とレイヤー毎ハイブリッド配置

DeltaNet からの系譜 (Linear Attention → RWKV/RetNet/GLA → DeltaNet → Gated DeltaNet → KDA) の中で、KDA は現時点で最も細かい粒度の忘却ゲートを持つ手法です。次章 Gated Attention は逆に、softmax 系 (KV を持つ全結合 Attention) の側にゲートを足すアプローチで、線形系の KDA とは出発点が異なります。
