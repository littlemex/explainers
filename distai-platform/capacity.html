どのリージョンで、何が、どう取れるか (2026-11-17 13:46 UTC)

結論から。アクセラレータの提供があることと、実際に取れることは別物である。たとえば trn2.3xlarge は 3 つのリージョンにしか無いが、ap-southeast-4 では spot の点が 9 で取りやすい。trn2.48xlarge は東京で spot の点が 9 だった。g6e.xlarge はどのリージョンでも spot の点が 1 で、spot では取りにくい。

この文書でやったこと。このアカウントで有効な 20 リージョンすべてについて、型の提供 (AZ ごと)、spot の価格と取りやすさの点、24 時間の Capacity Block の空き (8 日先まで)、vCPU の上限を AWS の API で集めた。実機の検証で「どこで何を取るか」を決めるときの最初の資料にする。

6. 分かっていないこと

  • on-demand で今取れるか。確かめる API が無い。提供と上限から「取れる可能性がある」までしか言えない。確かめるには実際に起動するしかない。
  • 参考にした資料との違い。AWS の GPU と AI アクセラレータのリージョンのまとめ (Zenn のスクラップ) は東京に trn2 が無いとしているが、2026-11-17 13:46 UTC の API では東京に trn2.48xlarge の提供があり、spot の点も 9 だった。
  • 時間による変化。spot の点と価格、Capacity Block の空きは時間で変わる。検証の前に、このページを作り直すスクリプトをもう一度流す。
