第 24 章 論文の中心的証拠である介入を実際にやった

この章の 3 行 第 22・23 章までは J space を読んでいただけだった。論文の一番強い証拠は読むのではなく操作する 実験で、それをようやく正しい形 (全位置・router 固定) で行った。 実 : 最強の対照 = 4.7 : 1 で論文の質的構造を再現したが、留保が 3 つある。

1. これまでの実験と、論文の実験の違い

これまでの章はすべて J space を読む実験だった。論文の一番強い証拠は読むのではなく操作する 実験で、ある概念の J space 座標を別の概念の座標と入れ替えると、出力が変わる確率が 純粋な入れ替えで 88%、J 成分だけの入れ替えで 59%、J に属さない残りの分散の入れ替えで 5% だったと 報告している。これは以前にも 1 回試みていたが、そのときは1 つの方向を 1 つの位置・1 つの層だけに 足す操作で、router (どの専門家に振るかを決める部分) も固定していなかった。論文の操作とは別物で、 その負の結果は今回の実験には何も言わない。

2. 今回の操作

2 つの語彙方向 V = [v_s v_t] (W_U J の 2 行) を取り、残差 h を この 2 次元平面に射影した係数 c = V⁺h を求める。その係数を入れ替える写像 σ を 適用し、h ← h + V(σ(c) − c) で残差そのものを書き換える。これを全トークン位置に、 L22 と L32 (どちらも論文が報告する 30% から 80% 深さの帯の内側で、線形性の基準も通過している層) に適用し、 router は入力側で固定する — 邪魔されていないパスで記録した 40 個の router 選択を、 操作後のパスにそのまま代入するので、測っている変化は入れ替えだけになる。

4. 留保 3 つ — 見出しに隠してはいけないもの

留保 1: ランダム語彙対がすでに real の半分以上ある rand_vocab (0.6844) は rand_plane (0.2332) よりずっと大きい。つまり「W_U J のどれかの語彙方向であること」 自体が効果の大半を持っている。概念対が正しいことは有意に勝つが、効果の主成分は「一般的な性質」であって 「その概念対に特有の性質」ではない。
留保 2: 答えが変わる割合はどの群でも 4% 前後で、論文の 88% ではない 操作を適用したのは L22 と L32 の 2 層だけで、論文のように 20 層の帯全体には適用していないので、 これは論文よりずっと弱い操作である。ゲートの用途にはむしろ都合の良い方向である — 読み出しは動くが答えは変わらない、というのはまさにゲートに求める性質 (答えを変えずに難易度だけを読む) だが、 論文の見出しの数字はここでは再現していないとはっきり書く。
留保 3: J の実効ランクは 448 で、探査した方向の数と一致する 「J に属さない成分」は「探査したことがない空間の成分」と混ざっている可能性があり、 4.7 倍という比はこの意味で真の対比の上限である。ただし non-J 側の取り分は L22 の 0.813 から L32 の 0.667 へ下がっており、深い層の J ほど verbaliser 方向を多く捉えていることは、 線形性と予測精度がどちらも深さとともに良くなるという、これまでの実測と同じ方向を向いている。

この章が示したこと

J space の座標は読み出しの副産物ではなく、verbaliser (モデルが不確かさを言葉にする準備) の因果的な 上流にある。第 22 章の「予測する」と、第 23 章の「配備条件で門として機能する」に、この因果的証拠が 加わったことで、残る問いは「この量が本物かどうか」ではなく「大きさと費用」に移る。
