MHA — マルチヘッドの構造と KV の重さ

すべての出発点。なぜ「ヘッドを分ける」のか、そして KV-Cache がなぜ効いてくるのか

0この章の狙い

この記事は Attention の基礎 (Query が Key を見て Value を混ぜる、なぜ $N^2$ で重いか、FlashAttention) を前提にします。まだの方は先に Softmax Attention をビジュアルに理解する を読んでください。

一言でいうと
MHA (Multi-Head Attention) は、Attention を 1 本ではなく $h$ 本のヘッドに分けて並列に行う仕組みです。各ヘッドが違う「見方」で関連を測り、最後に結合します。表現力は上がりますが、この後のシリーズで戦う相手 ― 推論で効いてくる KV-Cache のメモリ ― は、この MHA の「全ヘッドが自前の Key と Value を持つ」構造から生まれます。以降の MQA・GQA・MLA・SWA・DSA・線形 Attention (Mamba・DeltaNet 含む) は、ほぼすべてこの KV の重さをどう削るかの物語です (Gated Attention のように KV を変えず品質だけを上げる手法は例外です)。

1なぜヘッドを分けるのか

1 つの Attention では「1 種類の関連の測り方」しかできません。

素の Attention は、Query と Key の内積ひとつで関連度を決めます。しかし言語では、あるトークンは直前の単語との文法的なつながりを見たいこともあれば、遠くの主語との照応を見たいこともあります。1 本の内積では、これらを同時にうまく捉えきれません。

そこで MHA は、$d_{\text{model}}$ 次元のベクトルを $h$ 個の低次元ヘッド (各 $d = d_{\text{model}}/h$ 次元) に分割し、ヘッドごとに独立した Attention を並列に走らせます。各ヘッドは別々の射影行列を持つので、それぞれ違う「関連の観点」を学べます。最後に全ヘッドの出力を結合して 1 本に戻します。

ヘッド分割は「同じトークンを複数の観点から同時に見る」ための仕組みです。次元を割って並べるだけなので、総計算量は 1 本の Attention とほぼ変わりません (各ヘッドが $d_{\text{model}}/h$ 次元になるため。$h$ 本 × ヘッド次元 $d_{\text{model}}/h$ で相殺されます)。ただし、各ヘッドが自前の Key・Value を持つ点が、後で KV-Cache の重さとして効いてきます。

2数式で見る MHA

1 本の Attention を $h$ 本束ねるだけです。記号は本シリーズ共通のものを使います。

入力を $X \in \mathbb{R}^{N\times d_{\text{model}}}$ とします。ヘッド $i$ は自分の射影行列 $W_i^Q, W_i^K, W_i^V \in \mathbb{R}^{d_{\text{model}}\times d}$ で Q・K・V を作り、Attention を計算します。

# ヘッド i の Q,K,V (各 N×d)
Q_i = X W_i^Q,   K_i = X W_i^K,   V_i = X W_i^V
$$ \mathrm{head}_i = \mathrm{softmax}\!\left(\frac{Q_i K_i^{\top}}{\sqrt{d}}\right) V_i \in \mathbb{R}^{N\times d} $$

全ヘッドの出力を横に結合し、出力射影 $W^O \in \mathbb{R}^{d_{\text{model}}\times d_{\text{model}}}$ で混ぜ合わせます。

$$ \mathrm{MHA}(X) = \mathrm{Concat}(\mathrm{head}_1,\dots,\mathrm{head}_h)\, W^O $$
ポイントは KV ヘッド数 $n_{kv}$ という見方です。MHA では各ヘッドが自前の Key・Value を持つので $n_{kv}=h$ (Q ヘッドと同数)。この $n_{kv}$ こそが、次章 MQA / GQA で削りにいく数です。MHA は $n_{kv}=h$ で最大、という基準点にあたります。

3【構成】ヘッド分割のアーキテクチャ

ヘッド数スライダを動かして、1 本のベクトルが何本のヘッドに割られ、各ヘッドが自前の K・V を持つ様子を見ます。KV ヘッド数 $n_{kv}$ が Q ヘッド数と同じ ($=h$) なのが MHA の特徴です。

$d_{\text{model}}$ 次元の 1 本が $h$ 個のヘッド (各 $d=d_{\text{model}}/h$ 次元) に分割されます。MHA では Q・K・V が同数のヘッドを持つので、KV ヘッド数 $n_{kv}=h$。次章ではこの青 (Key) と緑 (Value) の本数を減らして、KV のメモリを削ります。

4計算量と KV-Cache

MHA は素の Attention と同じ重さです。だが推論では別の重さ ― KV-Cache ― が主役になります。

時間計算量 (学習 / Prefill)

スコア行列 $Q K^{\top}$ は各ヘッドで $N\times N$。全 $h$ ヘッド合わせると、ヘッド次元が $d=d_{\text{model}}/h$ なので、総計算量は 1 本の Attention と同じ$O(N^2 d_{\text{model}})$ になります (ヘッドで割った分が本数で戻る)。$N$ について二乗、というのは素の Attention と変わりません。

Decode 時のボトルネック

再計算を避けるために、過去のすべての Key と Value を保存しておいたものが KV-Cache です。1 トークンを生成するたびに、この KV-Cache を過去 $N$ トークン分 HBM から読み出します。読み出すバイト数も演算数もともに $N$ に比例して増えますが、読み出した各 K・V は Query 1 本分の内積にしか使えず再利用できないため、1 バイトあたりの演算数 (演算強度) が極端に低く、Decode は強く memory-bound になります。

KV メモリの大きさ

KV-Cache のバイト数は、本シリーズ共通のこの式で見積もれます。

$$ \text{KV bytes} \approx 2 \cdot N \cdot n_{kv} \cdot d \cdot b_{\text{KV}} \cdot L $$

先頭の $2$ は Key と Value の 2 つ分、$n_{kv}$ は KV ヘッド数、$d$ はヘッド次元、$b_{\text{KV}}$ は 1 要素のバイト数 (fp16 なら 2)、$L$ は層数です。MHA では $n_{kv}=h$ が最大なので、この式のすべての因子が最大値を取ります。次章以降は、この式の $n_{kv}$ (MQA/GQA)、$n_{kv}\cdot d$ (MLA)、$N$ (SWA・線形) をそれぞれ叩いて KV を削っていきます。

覚えておく基準: MHA の KV-Cache は $2 N h d\, b_{\text{KV}} L$。文脈長 $N$ が伸びるほど線形に膨らみ、長文 LLM ではモデル重みに匹敵、あるいは超える大きさになります。これは推論側では最大の動機のひとつです (学習・Prefill 側では $O(N^2)$ の時間計算量そのものを削ることも、SWA や線形 Attention 系にとっては大きな動機になります)。

5【体験】KV-Cache はどこまで膨らむか

文脈長 $N$・ヘッド数 $h$・層数 $L$ を動かして、MHA の KV-Cache が実際に何 GB になるかを見ます。fp16 (2 byte)、ヘッド次元 $d=128$ で概算します。

棒グラフは 1 シーケンスあたりの KV-Cache サイズです。$N$・$h$・$L$ のどれを上げても線形に膨らみ、長文・多ヘッド・深いモデルでは数十 GB に達します。バッチを増やせばさらに掛け算で増えます。このデモではヘッド次元 $d=128$ を固定しているため、$h$ (=$n_{kv}$) を下げると KV は素直に減ります。ただし MHA のまま $h$ そのものを減らすと、Q ヘッド数 (=表現力) も一緒に落ちてしまうのが問題です。次章の MQA / GQA は、この $h$ を保ったまま $n_{kv}$ だけを減らす発想です。スライダで $h$ を下げてみてください。

6系統上の位置 — 何が次章の課題になるか

MHA はすべての起点です。以降の手法は「MHA の何を削るか」で整理できます。

KV バイト式の因子 / 位置づけそれを叩く手法章

MHA の代表モデルは Transformer 原論文 (2017) をはじめ、初期の GPT・BERT などほぼすべての初期 LLM です。表現力の基準でありながら、KV-Cache が最も重い構成でもあります。なお MHA は比較的小さいモデルでは今も現役です。例えば Llama 2 は 7B/13B が MHA のままで、GQA を採用したのは 34B/70B のみでした。メモリ管理側の工夫としては、断片化を防ぐ PagedAttention も広く使われています。次章からは、この重さを削る旅が始まります。

結論。MHA の「全ヘッドが自前の K・V を持つ」構造は表現力を生む一方、KV-Cache という最大の重りを生みました。Attention の進化史とは、この式 $2Nhd\,b_{\text{KV}}L$ の各因子を、品質を保ったまま削っていく歴史そのものです。次章はまず $n_{kv}$ を叩く MQA / GQA へ進みます。
