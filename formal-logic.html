この回の前提: 第 01 回 形式検証とは何か

これから数回で、形式検証を支える論理の基礎体力を付けます。この回は一番の基本である命題論理 (propositional logic) です。「かつ」「または」「ならば」「でない」という、日常でも使う言葉を、誰が読んでも同じ結論になるように正確に定義し直します。

1. 命題と 4 つの論理演算子

命題 (proposition) とは、真 (true) か偽 (false) のどちらかに決まる文のことです。「2 は偶数である」は命題ですが (真)、「おいしい料理」は真偽が決まらないので命題ではありません。命題どうしを組み合わせる記号が 4 つあります。

P ∧ Q (P かつ Q, 論理積) ― P と Q が両方真のときだけ真。それ以外の 3 通り (片方だけ真、両方偽) はすべて偽になります。P ∨ Q (P または Q, 論理和) ― P と Q の少なくとも一方が真なら真。両方偽のときだけ偽になります。ここでの「または」は、両方成り立っていても真になる点に注意してください。日常語の「または」が「どちらか一方だけ」という意味で使われることがあるのとは違います。¬P (P でない, 否定) ― P が真なら偽、P が偽なら真。P → Q (P ならば Q, 含意) ― この記号だけは直感に反する場合があるので、次の節で詳しく見ます。

これらの記号の意味は、すべての組み合わせを並べた真理値表 (truth table) によって完全に決まります。言葉で説明するよりも、表を見れば一切のあいまいさが残りません。P と Q という 2 つの命題であれば、真偽の組み合わせは 2 × 2 = 4 通りしかないので、表はいつも有限で、すべての行を書き尽くせます。Software Foundations の Logic の章でも、否定 ¬P は P → False (P ならば偽が成り立つ) として定義されており、すべての論理演算子がこのようにごく少数の基本的な部品から組み立てられています。

2. 「ならば」の前件が偽なら全体は真になる

P → Q の真理値表は、P が真で Q が偽のときだけ全体が偽になり、残りの 3 通りはすべて真になります。特に戸惑いやすいのは、P 自体が偽のとき、Q が何であっても P → Q は真になるという点です。たとえば「豚が空を飛ぶならば、1 = 2 である」は、論理的には真の命題です。

これは「約束」として考えると理解しやすくなります。「雨が降ったら傘を持っていく」という約束をしたとき、実際に雨が降らなかった日に傘を持っていかなくても、約束を破ったことにはなりません。約束が破られたと言えるのは、前提 (雨が降った) が成り立ったのに結論 (傘を持っていく) が成り立たなかったときだけです。前提がそもそも成り立たない (P が偽) のであれば、約束は自動的に守られたことになり、全体は真になります。この「前提が偽なら全体が真になる」という性質は空虚な真 (vacuous truth) と呼ばれ、慣れるまでは直感に反して見えますが、真理値表という 1 つの定義から機械的に導かれる、矛盾の無い結論です。

図: P → Q の真理値表。偽になるのは P が真で Q が偽の 1 通りだけ。P が偽の 2 行は常に真。

3. 恒真式とド・モルガンの法則

命題の中には、P や Q にどんな真偽を当てはめても、常に真になるものがあります。これを恒真式 (tautology) と呼びます。代表例は P ∨ ¬P (排中律) で、P が真でも偽でも、P か ¬P のどちらかは必ず真になるので、全体は常に真です。恒真式は、特定の P や Q の意味に頼らず、論理の形だけから真であることが保証される命題です。反対に、どんな真偽を当てはめても常に偽になる命題は矛盾式 (contradiction) と呼ばれます。代表例は P ∧ ¬P で、P と ¬P が同時に真になることは無いため、常に偽になります。

もう 1 つの重要な法則がド・モルガンの法則 (De Morgan's laws) です。否定を ∧ や ∨ の中に押し込むと、記号が入れ替わります。¬(P ∧ Q) は ¬P ∨ ¬Q と同じ意味になり、¬(P ∨ Q) は ¬P ∧ ¬Q と同じ意味になります。Software Foundations の Logic の章にも、論理和の否定は否定の論理積になるという定理 de_morgan_not_or として、この法則の片方が示されています。

直感的に確かめてみましょう。「雨が降っていて、かつ風が強い」の否定は「雨が降っていない、または風が強くない (少なくとも一方が崩れる)」です。「両方成り立つ」の否定は「少なくとも一方が成り立たない」になる、というのがこの法則の意味です。

この法則が成り立つことは、真理値表を全部書き出して両辺を比べれば確認できます。P と Q の 4 通りの組み合わせそれぞれについて、¬(P ∧ Q) の値と ¬P ∨ ¬Q の値を計算し、すべての行で一致することを見れば証明が完了します。このように「すべての組み合わせを尽くして確認する」というやり方は、第 7 回以降で学ぶモデル検査の考え方そのものです。命題論理のように組み合わせが少ない場合はこの確認を手作業でもできますが、組み合わせが爆発的に増える場合は機械に任せる必要が出てきます。次回は、この命題論理に「すべての」「ある」という量化子を加えて、より表現力の高い言葉を手に入れます。
