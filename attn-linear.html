Linear Attention — softmax を外して O(N) に

ここから系統が分かれる。KV を減らす路線ではなく、softmax そのものを外し固定状態へ書き換える路線

0この章の狙い

この記事は Attention の基礎、および前章までの MHA の構造 (ヘッド分割・KV-Cache の式) を前提にします。まだの方は先に Softmax Attention をビジュアルに理解する と 前章: MHA — マルチヘッドの構造と KV の重さ を読んでください。

ここが系統の分岐点です。 MQA・GQA・MLA・SWA・DSA は、すべて MHA が持つKV-Cache という「参照するもの」を減らす・選ぶ路線でした。KV は $N$ に比例して増え続けるという前提そのものは変えません。Linear Attention はこの前提を崩します。softmax を外すと、KV を全部持たなくても、固定サイズの状態 $S$ に情報を畳み込んで持ち運べることが分かります。ここから「線形 / 状態系」という第 2 の系統が始まります。
一言でいうと
softmax があるせいで $QK^\top$ という $N\times N$ の行列を作らざるを得ませんでした。softmax を外し、カーネル内積 $\phi(q)^\top\phi(k)$ に置き換えると、行列積の結合則が使えるようになり、$(\phi(K)^\top V)$ を先に $N$ に依らない固定サイズへ畳み込んでから $\phi(Q)$ を掛けられます。これで計算量が $O(N^2 d)$ から $O(N d^2)$ に落ち ($N \gg d$ の長系列で効きます)、KV-Cache の代わりに状態行列 $S$ (サイズ固定) を持てば十分になります。

1何を解決する手法か

softmax があるかぎり、$QK^\top$ を丸ごと作るしかない。

前章までの MQA・GQA・MLA・SWA・DSA は、いずれも「KV をどう減らす・選ぶか」という同じ土台の上で工夫していました。しかし、その土台自体 ― KV-Cache が $N$ に比例して増え続けるという構造 ― は誰も変えていません。素の Attention に戻って考えると、この構造は $\mathrm{softmax}(QK^\top/\sqrt d)V$ という式の $\mathrm{softmax}$ の存在に由来します。$\mathrm{softmax}$ は各クエリ $q_t$ について $\exp(q_t^\top k_s)$ を全キー $s\le t$ で計算してから正規化するため、$Q$ と $K$ の間に他の演算を挟めず、$N\times N$ のスコア行列を必ず経由してしまいます。だからこそ、これまでの章は「KV というデータそのもの」を削るしかなかったのです。

ここで問われる着想はシンプルです。もし softmax がなければ、$QK^\top V$ の計算順序を変えられるのではないか。実際、$\mathrm{softmax}$ を外して $\exp(q_t^\top k_s)$ を別のカーネル $\phi(q_t)^\top \phi(k_s)$ に置き換えると、行列積の結合則が使えるようになります (これは指数カーネルの近似ではなく、類似度関数そのものの置き換えです。$\exp$ を不偏推定で近似する路線には Performer (FAVOR+, arXiv:2009.14794) があります)。$(QK^\top)V$ を先に計算する代わりに、$Q(K^\top V)$ の順で計算してよくなり、$K^\top V$ は $N$ に依存しない固定サイズの行列に畳み込めます。Katharopoulos et al. の "Transformers are RNNs" (arXiv:2006.16236) が示したのは、まさにこの置き換えにより Attention が固定状態を持つ RNN と等価になるという事実です。

KV を減らす路線と、KV をやめる路線。 これまでの章は「MHA の $2Nn_{kv}db_{\text{KV}}L$ という式のどの因子を叩くか」でした。Linear Attention はこの式自体を手放し、$N$ 依存が消えた固定サイズの状態 $S$ に置き換えます。得るものは $O(N d^2)$ の計算量と一定サイズのメモリ、失うものは「どんな遠いトークンでも厳密に参照できる」という素の Attention の強みです (この代償は次節以降で詳述します)。

2数式で見る Linear Attention

$\mathrm{softmax}$ をカーネル内積に置換すると、Attention は状態の累積更新として書けます。記号は本シリーズ共通のものを使います。

素の Attention は $\mathrm{softmax}(QK^\top)V$ で、指数カーネル $\exp(q_t^\top k_s)$ を経由していました。これを特徴写像 $\phi(\cdot)$ の内積に置き換えます (なお $\sqrt d$ によるスケーリングは $\phi$ の設計に吸収できるため、以降は省略して書きます)。

$$ \exp(q_t^\top k_s) \;\longrightarrow\; \phi(q_t)^\top \phi(k_s) $$

この置き換えにより、(softmax の正規化を一旦除いた) 出力の分子部分は次のように書けます。

$$ QK^\top V \;\longrightarrow\; \phi(Q)\big(\phi(K)^\top V\big) \quad (\text{正規化前}) $$

右辺の $\phi(K)^\top V$ は $d_k\times d_v$ の固定サイズの行列です。これを時刻ごとの累積として書き直すと、状態行列 $S_t$ の更新式になります。

# 状態 S_t は d_k×d_v の固定サイズ (系列長 N に依存しない)
S_t = S_(t-1) + φ(k_t) v_tᵀ
# 正規化項 z_t も同様に累積
z_t = z_(t-1) + φ(k_t)
$$ S_t = S_{t-1} + \phi(k_t)\, v_t^\top, \qquad z_t = z_{t-1} + \phi(k_t) $$

出力 $o_t$ は、この状態 $S_t$ にクエリ側の特徴写像 $\phi(q_t)$ を掛けて正規化するだけで得られます (以下は $o_t$ を列ベクトルとして書いた形です。$\phi$ の出力次元は一般に $d_k$ と異なってもよく、その場合 $S_t$ は $d_\phi\times d_v$ になります)。

$$ o_t = \frac{S_t^\top \phi(q_t)}{z_t^\top \phi(q_t)} $$
Attention が softmax という非線形を持つ間は、$Q$・$K$・$V$ の演算順序を変えられませんでした。カーネル内積への置き換えで線形にした瞬間、結合則が使えるようになり、$(\phi(K)^\top V)$ を先に畳み込んで持ち運べる ― これが Linear Attention の核心です。$S_t$ が $d_k\times d_v$ の固定サイズで、系列長 $N$ にまったく依存しない点に注目してください (以降の DeltaNet 系では分母 $z_t$ を落とし、正規化を別の形で行うのが主流です)。

3計算量

KV-Cache という概念そのものが、$N$ に依存しない状態 $S$ に置き換わります。

時間計算量 (prefill / 学習時)

各時刻の状態更新 $S_t = S_{t-1} + \phi(k_t)v_t^\top$ は $\phi(k_t)$ ($d$ 次元) と $v_t$ ($d$ 次元) の外積で $O(d^2)$、これを $N$ ステップ繰り返すので、時間計算量は$O(N d^2)$ です。素の Attention の $O(N^2 d)$ から $N$ の依存が二乗から線形に落ちます。

ただし、この逐次再帰形をそのまま $N$ ステップ順番に処理すると GPU 上で並列性が乗りません。実際の学習では、並列形 ($\phi(Q)(\phi(K)^\top V)$ に causal mask を掛ける形) や、系列をチャンクに分けて並列化する chunkwise 並列 (GLA の "Hardware-Efficient Training" や、DeltaNet の並列化 arXiv:2406.06484 が採用する方式) が使われます。再帰形は推論 (decode) 向き、並列形/チャンク形は学習向きという 2 つの顔がある点に注意してください。

Decode 時のボトルネック

1 トークンを生成するたびに、素の Attention は過去 $N$ 件分の KV を HBM から読み直す必要がありました。Linear Attention では、次のトークンの出力を出すのに必要なのは直前の状態 $S_{t-1}$ だけです。KV を読み出す必要がなく、固定サイズの状態を更新するだけで decode が完結します。

KV / 状態メモリの $N$ 依存

状態 $S$ は $d_k\times d_v$ の固定サイズの行列であり、系列長 $N$ が伸びても状態のサイズは変わりません。これまでの章の $2Nn_{kv}db_{\text{KV}}L$ という式が $N$ について線形に増え続けるのに対し、Linear Attention はこの式ごと「$N$ 非依存の固定状態」に置き換えます。

O(N d²)時間計算量

4【構成】softmax 版 vs 線形版

softmax 版は $N\times N$ の行列を作り続けます。線形版は左から右へ、固定サイズの状態を再帰的に更新するだけです。トグルで切り替えてください。

Query Key Value / 状態 S

softmax 版は、各クエリが全キーとの内積を取るため、$N\times N$ のスコア行列 (系列長に応じて面積が増える) を経由します。線形版に切り替えると、代わりに固定サイズの箱 (状態 $S$) が $S_0$ から $S_9$ までタイムライン上に並び、各トークンの $\phi(k_t)v_t^\top$ を反映して箱のサイズを変えずに更新されていく様子が見えます。系列がどれだけ長くなっても、箱の大きさは変わりません。

5【体験】系列長を伸ばすと何が起きるか

系列長 $N$ スライダを動かして、softmax 版のメモリ (KV-Cache, $N$ に線形に増加) と線形版のメモリ (状態 $S$, 常に一定) を比較します。

$N$ を伸ばすほど、softmax 版の KV-Cache (橙の棒) は線形に伸び続けます。一方、線形版の状態 $S$ (緑の棒) は$N$ に一切依存せず、常に同じ高さのままです。これが「KV を持つか、固定状態を持つか」という 2 系統の分岐点そのものです。ただし、この一定の状態には有限の容量という別の制約があり、それは次章 DeltaNet で詳しく扱います。

なお §4 のスコア行列 ($N\times N$) は計算中に一時的に経由する中間テンソルで (FlashAttention 等ではタイル分割され実体化すらしません)、生成時にずっと持ち続けるメモリは KV-Cache であり、これは $N$ に線形です。時間計算量 $O(N^2 d)$ 自体は変わらない点に注意してください。

6代表モデルと系統上の位置

Linear Attention は「線形 / 状態系」という第 2 の系統の起点です。MHA から分岐し、RWKV・RetNet・GLA を経て DeltaNet 系へ精緻化されていきます。

Linear Attention の骨格は Katharopoulos et al. "Transformers are RNNs: Fast Autoregressive Transformers with Linear Attention" (arXiv:2006.16236, 2020-06) で示されました。実運用のモデルというより、softmax をカーネル内積に置き換えると Attention が固定状態の RNN と等価になるという理論的な転換点を示した論文実験が起点です。

この骨格を土台に、RWKV (arXiv:2305.13048、系譜的には AFT (Attention Free Transformer) にも連なる)・RetNet (arXiv:2307.08621)・GLA (Gated Linear Attention, arXiv:2312.06635) が、状態更新に減衰やゲートを加える改良を重ね、研究から中規模モデルでの検証を重ねてきました (RWKV は 14B 級まで到達)。さらに、Lightning Attention (Qin et al. の TransNormerLLM / Lightning Attention-2、arXiv:2401.04658、2024) を採用した MiniMax-01 (arXiv:2501.08313、2025-01) は、Lightning Attention ブロック 7 層につき素の Softmax Attention ブロックを 1 層挟むハイブリッド構成 (8 層周期・80 層中 10 層が softmax) で、総パラメータ 456B (活性化 45.9B の MoE) の量産スケールに Linear Attention 系を載せた到達点です。これらを経て、状態更新を「誤差修正」の形に精緻化する DeltaNet (次章) へとつながります。

系統上の位置。 Linear Attention の親は MHA (前章までの「素の Attention」) ですが、そこから分岐する先は MQA・GQA・MLA・SWA・DSA とは別の系統です。MHA を起点に「KV を減らす・選ぶ」softmax 系と、「softmax を外し固定状態で再帰する」線形 / 状態系の 2 本の道に分かれる ― この章がその分岐点にあたります。次章 DeltaNet は、この固定状態の「書き込み方」を精緻化する最初の一手です。
