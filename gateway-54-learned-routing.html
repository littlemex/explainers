学習させれば振り分けに使えるか
5 割に見えた数字と、残った 1 割

この章の結論。第 50 章では、学習なしの決定モデルは振り分けの信号にならないと分かりました。そこで SR が描く次の一手どおりに、Lux の内部の数値 (隠れ状態) を固定の特徴にして、RouterBench の結果から振り分けを学習させました。

安い側を mistral-7b にすると、見たことのないデータセットでも賞金の 53.5% を取りました。しかしこの数字は、かなりの部分が安いモデルの壊れ方と重なっていました。mistral は 4,424 問中 2,904 問で「A」とだけ答えていて、 学習したルータは、その 2,904 問の中で mistral が外す問題 (= 正解が A でない問題) を AUC 0.84 で見分けていました。正解が A かを読み取っている可能性が高いのですが、経路は確かめていません。A 以外を答えた 1,520 問だけでは 30.1% でした。

安い側を、そうした偏りの小さい mixtral にすると、残った信号は賞金の 1 割ほどでした。一番厳しい分け方 (仕事の系統ごと外す) で +9.0%、語の出現を数えるだけの特徴 (TF-IDF) より +6.3 ポイント上です。 事前登録した「有用」の条件は形式上満たしましたが、小さい信号です。

1. 何を学習させたか

第 50 章と同じ RouterBench の 4,424 問を使い、Lux には「専門知識や多段の推論が要るか」の Noul を 1 回聞いて、その行の 3 か所 (行の最後と、true・false それぞれの選択肢の最後) の隠れ状態を取り出しました。 これを固定の特徴として、ridge 回帰 (線形の回帰に、係数を小さく保つ罰を足したもの) で「GPT-4 の正誤 − 安いモデルの正誤」を予測させます。罰の強さは、学習側の中だけで分けた 3 分割で選びました。

評価の分け方は 3 通りです。問題単位 (同じデータセットの別の問題で学習)、データセット単位 (評価するデータセットは学習に一度も出てこない)、系統単位 (MMLU の 57 科目や中国語の問題群などをひとまとめにして外す)。 比べる相手は、同じ回帰に語の出現を数えた特徴 (TF-IDF、学習は要るがモデルは要らない) を入れたもの、データセット名や Vela の分野での表引き、そして第 50 章の学習なしの確率です。 どれも結果を見る前に決めた手順で、事前登録の「有用」は「データセット単位で区間の下限が 5% を越え、かつ TF-IDF を上回る」でした。

2. 5 割に見えた数字

最初の結果は驚くほど良く、mistral の組で問題単位 +59.2%、データセット単位 +53.5%、系統単位 +44.1% でした。この連載はこれまで「学習したルータは 1 つのカテゴリの表引きに負ける」を繰り返し確かめてきたので、まず漏れを疑いました。

見つかったのは RouterBench の mistral-7b の答え方です。4,424 問中 2,904 問で、mistral は「A」とだけ答えていました (文字だけで答えた 3,075 問のうち 94.4% が A)。 その 2,904 問で mistral が当たっていたのは 27.7% で、これは 4 択の正解が A である割合とほぼ同じです。 つまり、この組の「安いモデルが当たるか」は、選択式ではほぼ「正解が A か」と同じです。

確かめ方は 2 つです。mistral が A と答えた 2,904 問の中で、学習したルータの点数が「mistral が外す問題」を見分ける力を測ると AUC 0.84 でした。正解が A かどうかを読み取っている可能性が高いのですが、問題の難しさやデータセットの手がかりなど別の経路も否定できていません。 そして A 以外を答えた 1,520 問だけで捕獲率を測ると、53.5% が 30.1% に下がりました。A への偏りと重なった分は大きいのですが、全部ではありません (ただし 1,520 問は分布の違う部分集合なので、差の 23 ポイントをそのまま「見せかけの量」とは読めません)。 残りの 30% にも、mistral の別の壊れ方 (書式の失敗など) が混ざっている可能性があり、調べていません。

[訂正] 第 50 章の主な組は、この mistral の組でした。 第 50 章の学習なしの信号の数字 (最良 +7.0%) もこの交絡を含んでいます。第 50 章には訂正を入れ、交絡の小さい mixtral の組では学習なしの信号はどれも正にならなかった (Lux の 3 つは −1.2〜−3.4%、35B の 3 つは −1.4〜−7.5%) ことを明記しました。

3. 残った 1 割

mixtral-8x7b も 4,424 問中 3,435 問で文字だけを答えますが、そのうち A は 29.7% (4 択なら偏りが無くて 25%) で、mistral の 94.4% ほど偏っていません。こちらの組で同じことを測りました。

読み取れることは 3 つです。

  • 事前登録の「有用」は形式上満たしました (未見のデータセットで下限 +8.1% > 5%、点推定 +13.0% > TF-IDF の +11.1%)。ただしこの分け方では TF-IDF との差は区別できません。
  • 未見の系統では、Lux の特徴が TF-IDF より上でした (全体の差 +6.3 [+0.7, +13.3])。内訳 (MMLU とそれ以外、文字だけの答えを除く) でも点推定は同じ向きですが、内訳ごとの区間は出していない探索的な値です。
  • ただし大きさは賞金の 1 割ほどで、一番厳しい分け方の下限 (+4.7%) は、第 50 章の合格線 (5%) のわずかに下です。MMLU が 77% を占めるので、系統単位の全体の値は「MMLU 以外で学んで MMLU を当てる」に強く引っ張られています。

4. tierbook にとっての意味

tierbook は「学習したものは提案であって証拠ではない」(predict.py) とし、別の問題の組での区間の下限で認めるかどうかを決める仕組みです。今回の結果は、ちょうどその仕組みが役に立つ形をしています。

  • mistral の 5 割は、下限で見ても通ってしまう数字でした (+48.2% が下限)。区間は安いモデルの壊れ方との重なりを見抜けません。気付けたのは、安いモデルの答えそのものを読んだことです。 「振り分けの得のラベルを使う前に、安いモデルの答えの分布を数える」は、どの研究でも要る測定として記録する価値があります (tierbook の方針どおり、拒否の規則ではなく測定として)。
  • ルータ自身が問題を解ける強さを持つと、ラベルの壊れ方を読み取れてしまう可能性がある。決定モデルが配信先より賢い場合には、この交絡が入り得ます。
  • mixtral で残った信号は、tierbook の線で見ると「下限が合格線の近くを行き来する小さい信号」です。今の段階で型を足して取り込む理由にはなりませんが、第 50 章で「今はやらない」とした判断 (外の判定器を照合できる型) を、測定の記録として残す対象が 1 つ増えました。

まだ言えないこと

  • 特徴は Lux の 1 つの質問の行だけで、回帰は線形です。質問を変える、層を変える、非線形にすると大きさは変わる可能性があります。
  • RouterBench の 1 つの標本・1 回の実行で、MMLU が 77% を占めます。
  • mistral の残りの 30% の中身と、mixtral にも A への偏り (文字だけの答えの 29.7%) が少し残っていることの影響は、分けきれていません。
  • 決定モデル自体を RouterBench で学習させる (Kai の fine-tuning の道具など) は試していません。今回は内部の数値を固定したままの回帰です。

特徴: Lux-9B (bd45a30) の Noul「Does this request require expert knowledge or multi-step reasoning to answer correctly?」の行の query 位置と true/false 候補の終端 (各 4,096 次元)、bf16。 回帰: 双対形の ridge、λ ∈ {0.1, 1, 10, 100, 1000} を学習側の内側 3 分割で選択。TF-IDF は語を 16,384 個の枠に振り分けた出現数。 事前登録は 2026-09-24 17:30 JST (PREREG.md の D)。
