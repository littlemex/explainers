Mamba / Mamba2 — 選択的状態空間モデル

線形 Attention と同じ固定状態の骨格を、制御理論の状態空間モデルから導く

0この章の狙い

この記事は Attention の基礎、そして前章 DeltaNet / Gated DeltaNet で見た「固定サイズの状態を再帰で更新する」骨格を前提にします。まだの方は先に Softmax Attention をビジュアルに理解する と Linear Attention — softmax を外して O(N) に を読んでください。

一言でいうと
Mamba / Mamba2 は、線形 Attention や DeltaNet と同じ「固定サイズの状態を再帰更新する」骨格を、制御理論の状態空間モデル (State Space Model, SSM) という別の出発点から導いた手法です。状態更新の行列 (何を書き込み、何を忘れるか) をトークンごとに入力依存にする「選択 (selective)」という発想が肝で、これにより SSM は文脈に応じて伝播と忘却を切り替えられるようになりました。Mamba2 はこの選択的 SSM を Structured State Space Duality (SSD) という理論で線形 Attention 側の chunk 並列計算と結び付け、学習を大幅に高速化しています。

1何を解決する手法か

線形 Attention・DeltaNet はどちらも「固定サイズの状態 $S_t$ を再帰更新する」という骨格を持っていました。Mamba はこの骨格を、Attention とは別の系譜 — 制御理論の状態空間モデル — から導き出します。

前章までで見た線形 Attention や DeltaNet は、softmax Attention から出発して「カーネル近似」や「delta 則」という道筋で状態の再帰更新に行き着きました。Mamba はまったく別の入口から同じ場所に着きます。制御理論には古くから、連続時間の入力 $x(t)$ を隠れ状態 $h(t)$ を介して出力 $y(t)$ に写す状態空間モデル (SSM) という枠組みがあります。これを離散化し深層学習に持ち込んだのが S4 系の研究で、Mamba はその系譜の上に立っています。

ただし従来の SSM には弱点がありました。状態更新に使う行列が入力に関わらず固定 (time-invariant) だったため、「今のトークンをどれだけ状態に書き込むか」「過去をどれだけ忘れるか」を文脈に応じて変えられませんでした。これは線形 Attention が特徴写像 $\phi$ を固定していたのと同じ種類の制約です。Mamba の核心的な着想は、この状態更新の行列を入力トークンごとに変える (選択的にする)ことです。同じ「固定サイズ状態の再帰更新」という骨格の中で、伝播と忘却の強さをトークンごとに選べるようにした点が、Mamba を単純な SSM から区別します。

Mamba の着想は一言で言えます。「状態への書き込み・保持・出力の強さを、トークンの内容によって選ばせる」。線形 Attention や DeltaNet と同じ固定状態の再帰という土台の上に、制御理論の SSM を経由して「選択性」という軸を持ち込んだのが Mamba です。

2数式で見る選択的 SSM

SSM の基本形は状態 $h_t$ を線形に更新し、線形に読み出すだけの単純な式です。Mamba はこの中の行列を入力依存にします。記号は本シリーズ共通のものを使います。

離散化された SSM の基本形は次の 2 式です。

$$ h_t = A h_{t-1} + B x_t $$ $$ y_t = C h_t $$

$h_t$ が固定サイズの状態、$x_t$ が時刻 $t$ の入力、$y_t$ が出力です。$A$ は状態がどれだけ自分自身を保持する (あるいは減衰する) かを決める行列、$B$ は新しい入力をどれだけ状態に書き込むかを決める行列、$C$ は状態から出力をどう取り出すかを決める行列です。従来の S4 系 SSM では $A, B, C$ はすべて時刻 $t$ に依らず固定でした。

# 従来の SSM: A, B, C は入力 x_t に関わらず固定
h_t = A h_{t-1} + B x_t
y_t = C h_t

Mamba の「選択 (selective)」は、この $B, C$ と離散化の時間幅を決めるステップサイズ $\Delta$ を入力 $x_t$ の関数にすることです。

$$ B_t = B(x_t), \quad C_t = C(x_t), \quad \Delta_t = \Delta(x_t) $$ $$ h_t = A_t h_{t-1} + B_t x_t, \qquad y_t = C_t h_t $$

$\Delta_t$ は連続時間の SSM を離散化する際のステップ幅で、$\Delta_t$ を通して $A_t$ も実質的に入力依存になります (離散化の詳細な式は本稿では扱いません)。この選択性により、Mamba はトークンごとに「この入力を強く状態に書き込むか、素通りさせるか」「過去をどれだけ保持するか」を切り替えられます。線形 Attention の特徴写像 $\phi$ や DeltaNet の書き込み強度 $\beta_t$ が担っていた役割を、SSM の言葉で $B_t, C_t, \Delta_t$ が担う、という対応関係で理解すると位置づけがはっきりします。

ポイントは $B, C, \Delta$ を入力依存にするかという一点です ($A$ は学習される固定パラメータのままですが、$\Delta_t$ を介して実効的な $A_t$ は入力依存になります)。固定なら従来の (選択的でない) SSM、入力依存なら Mamba の選択的 SSM です。状態 $h_t$ 自体は依然として固定サイズで、これは前章までの $S_t$ (線形 Attention・DeltaNet の状態) と同じ役割を果たします。

3計算量

選択的 SSM も線形 Attention・DeltaNet と同じ骨格を持つので、計算量の性質も同じ系統に属します。

時間計算量 (学習 / Prefill)

状態更新が各時刻 $O(1)$ の固定サイズ演算なので、系列長 $N$ に対して $O(N)$ です。ただし単純な逐次再帰は GPU の並列性を活かせないため、Mamba はハードウェア対応のスキャン (parallel scan) アルゴリズムで並列化します。Mamba2 はさらに、状態遷移行列 $A_t$ を単純化した形について、この選択的 SSM の計算が線形 Attention の chunk 単位の行列演算と等価であることを示す Structured State Space Duality (SSD) という理論を導入し (詳細は §6)、行列乗算に還元することで学習を大幅に高速化しました。

Decode 時のボトルネック

1 トークン生成ごとに読み直すのは固定サイズの状態 $h_t$ だけで、KV-Cache のように過去 $N$ トークン分の Key・Value を読み直す必要がありません。純粋な Mamba 層では KV-Cache は不要 (ハイブリッド構成では Attention 層の分のみ必要) になるため、線形 Attention・DeltaNet と同様に KV-Cache 読み出しに起因する $N$ 依存の memory-bound 負荷から離脱できます。

KV / 状態メモリの $N$ 依存

状態 $h_t$ は固定サイズで系列長 $N$ に依存しません。前章までで見た「固定状態は有限容量の連想記憶であり、厳密な長距離参照は原理的に犠牲になる」という制約は、選択的 SSM にも同様に当てはまります。

Mamba の計算量の骨格は前章までの線形 Attention・DeltaNet と同じ「$O(N)$、状態固定」です。異なるのは、この骨格を SSM という別の理論から導き、状態更新の行列を入力依存にする「選択」を持ち込んだ点です。

4【構成】固定状態の再帰更新

系列を左から右へ流しながら、固定サイズの状態 $h$ を再帰的に更新していく様子を見ます。MHA のように KV を系列長分溜め込む構成と対比してください。

系列位置
入力トークン x_t 固定サイズ状態 h_t 出力 y_t

MHA では系列が進むほど Key・Value の列がどんどん溜まっていきますが、Mamba では状態 $h_t$ のサイズが常に一定のまま、内容だけが $A_t, B_t$ に従って上書きされていきます。選択的な $B_t, C_t$ により、各トークンが状態に与える影響の強さはトークンごとに変わります。

5【体験】状態サイズは N に依存しない

系列長 $N$ を伸ばしたとき、MHA の KV-Cache が線形に増えるのに対し、Mamba の状態サイズが一定であることを棒グラフで対比します。

系列長 $N$
8K系列長 N
—MHA の KV (相対値)
一定Mamba の状態 (相対値)

スライダで $N$ を伸ばすと、MHA 側の棒はどんどん高くなりますが、Mamba 側の棒は常に同じ高さのままです。これが「固定サイズ状態」の意味するところで、長い文脈でもメモリ使用量が頭打ちになる一方、前章までで触れた通り厳密な長距離参照は犠牲になります。なお系列長が十分短い間は MHA の KV の方が固定状態より小さいこともあり、固定状態が効いてくるのはむしろ長い文脈で KV が伸び続けたときです。

6代表モデルと系統上の位置

Mamba は線形 Attention と同じ「固定状態の再帰」骨格を、SSM という別の理論的入口から実現した手法です。

Mamba は Gu と Dao による "Mamba: Linear-Time Sequence Modeling with Selective State Spaces" (arXiv:2312.00752, 2023-12) で提案されました。状態更新の行列を入力依存にする選択性と、ハードウェア対応のスキャンアルゴリズムにより、SSM を実用的な系列モデリング手法として確立しました。代表的な適用例に Mamba 3B や、Attention 層と Mamba 層を混在させた Jamba があります。

Mamba2 は同じ著者らによる "Transformers are SSMs: Generalized Models and Efficient Algorithms Through Structured State Space Duality" (arXiv:2405.21060, 2024-05) で、状態遷移行列 $A_t$ をスカラー×単位行列に制限した形に単純化することで、選択的 SSM の計算と線形 Attention の chunk 並列計算が数学的に等価であることを SSD 理論で示し、行列乗算ベースのアルゴリズムで学習を高速化しました。Mamba2 系の代表的な実運用モデルには Codestral Mamba (Mistral AI) があり、また NVIDIA の Nemotron-H は Mamba2 を主体に一部の層だけ GQA (全結合系) を挟むハイブリッド構成を採用していると報告されています。

ヘッジ (重要)。「Mamba3」と呼ばれる手法について、本稿執筆時点で正式な論文を特定できていません。シリーズ目次の系統図には将来ノードとして薄く載せますが、本章では数式・数値を一切示しません。

線形 Attention・DeltaNet・SSM は、出発点 (softmax のカーネル近似か、delta 則か、制御理論の SSM か) こそ異なりますが、いずれも「固定サイズの状態を再帰で更新する」という同じ骨格の変奏です。次章 KDA は DeltaNet 系の忘却ゲートをさらに細粒度化する方向に進みます。
