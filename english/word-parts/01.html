単語を部品の絵で組み立てる ・ 第 1 回

単語は 3 つの部品 — 向き、芯、服

長い単語は暗記するものではなく、積み木を組み立てたものとして読めます。

← 語彙の仕組みシリーズの目次へ

長い英単語を見ると、それだけで身構えてしまう人は多いと思います。この回では、単語を「向き」「芯」「服」という 3 つの部品に分ける絵を手に入れます。読み終わるころには、unpredictable のような単語を見ても、部品から意味の見当がつけられるようになります。

長い単語は 3 つの積み木でできている

unbelievable という単語は 12 文字もあります。でも、これを 1 つのかたまりとして覚える必要はありません。よく見ると、un と believe と able の 3 つの積み木が並んでいるだけです。

真ん中の芯が意味の中心で、前の部品が向きを足し、後ろの部品が品詞を決めています。

このシリーズでは、3 つの部品をこう呼びます。

  • 芯 (語根) は、単語の意味の中心です。
  • 向き (接頭辞) は、芯の前について、方向や打ち消しを足します。
  • 服 (接尾辞) は、芯の後ろについて、名詞・形容詞・動詞・副詞のどれになるかを決めます。

The story was unbelievable.

その話は信じられないものでした。

芯 — 意味の中心になる語根

芯は、単語の意味の中心です。1 つの芯を覚えると、その芯を持つ単語がまとめて読めるようになります。たとえば port は「運ぶ」という芯です。

オレンジの芯は変わらず、まわりにつく部品だけが入れ替わっています。

export も import も transport も portable も、別々の 4 つの単語として覚えるより、「運ぶ」という 1 つの芯に部品がついたものとして見るほうがずっと楽になります。

Japan exports cars and imports oil.

日本は車を輸出し、石油を輸入しています。

I bought a portable speaker.

持ち運べるスピーカーを買いました。

向き — 芯の前につく接頭辞

向きの部品は、芯の前について「どちらへ」を足します。いちばんわかりやすいのは、境界の外へ出るのか、中へ入るのか、通り抜けるのかという 3 つの向きです。

緑の箱を境界として見ると、ex- は外へ出る矢印、im- は中へ入る矢印、trans- は通り抜ける矢印になります。

translate も「ことばを向こう側へ運ぶ」と見ると、「翻訳する」という意味につながります。向きの部品には、ほかに「もう一度」の re- や「前もって」の pre- などがあり、第 2 回でまとめて絵にします。

Please use the exit on the left.

左側の出口をご利用ください。

Can you translate this email into Japanese?

このメールを日本語に訳してもらえますか。

服 — 後ろにつく接尾辞が品詞を決める

服の部品は、芯の後ろについて品詞を決めます。同じ芯でも、着る服によって名詞になったり、形容詞になったりします。人が同じでも、服を替えると役割が変わるのと同じです。

服着替えた先例
-tion名詞 (すること、されたもの)inform → information
-ness名詞 (状態)kind → kindness
-ment名詞 (すること、その結果)develop → development
-able形容詞 (〜できる)read → readable
-ful形容詞 (〜に満ちた)care → careful
-ize動詞 (〜にする)modern → modernize
-ly副詞 (〜なやり方で)quick → quickly

服を見れば、意味がわからなくても文の中での役割はわかります。たとえば -ness で終わる単語は、名詞として主語や目的語の場所に入ると予想できます。

Thank you for your kindness.

ご親切にありがとうございます。

Please drive carefully.

気をつけて運転してください。

carefully は care + ful + ly で、服を 2 枚重ね着しています。「気づかいに満ちた」という形容詞に、さらに「〜なやり方で」という副詞の服を重ねた形です。

分解の手順と、気をつけること

知らない単語に出会ったら、次の順番で分けてみてください。

  1. 後ろの服を見て、品詞の見当をつけます。
  2. 前の向きを見て、方向や打ち消しがあるかを確かめます。
  3. 残った芯の意味を考え、全体をつなげます。

unpredictable で試してみます。服は -able なので形容詞です。向きは un- (〜でない) と pre- (前もって) の 2 つです。芯の dict は「言う」です。つなげると「前もって言うことができない」となり、「予測できない」という意味にたどり着きます。

The weather here is unpredictable.

ここの天気は予測がつきません。

部品の意味はヒントであって、答えそのものではありません。

  • prevent は pre- (前に) + vent (来る) で、「先回りして来る」から「防ぐ」になりました。部品と今の意味のあいだに 1 歩のつながりが入ることがあります。
  • inflammable の in- は打ち消しではなく「中へ」で、「燃えやすい」という意味です。同じ形の部品が、別の意味を持つことがあります。
  • read や real の re は部品ではありません。分けられそうに見えても、分けない単語もあります。

部品で見当をつけたら、最後は文の流れと辞書で確かめてください。
