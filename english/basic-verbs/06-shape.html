基本動詞をイメージで理解する ・ 第 6 回

start と break — 始まり、終わり、手を加える

stop は途中で止まるだけ、finish は残りがゼロになる。break は境目がでたらめ、cut は自分で線を決める。

← 基本動詞シリーズの目次へ

線の端をどう扱うかで start と stop と finish が分かれ、分け方の意図で break と cut が分かれます。rise と raise、fall と drop のように「自分で動くか、動かすか」で対になる語もここで整理します。12 枚で、動きと変形の語をまとめます。

緑 = 基準や相手
オレンジ = 主役（動く側、変わる側）
破線 = まだそうでない、または見えない

まちがえやすい組み合わせ絵を並べると違いが一瞬でわかる
