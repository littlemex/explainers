have と take — 手の内に入れる

have は動かす動詞ではなく「自分の圏内にある」と言う動詞です。take はそこへ引き込む、give は外へ出す動きです。

← 基本動詞シリーズの目次へ

この回の 11 枚は、物が自分の手の届く範囲に入るか出ていくかで並んでいます。have が圏内、take が引き込む、give と send が外へ出す、put と set が位置を決める、hold と keep が押さえる、leave が残して離れる、lose が落とす、find が見つける。bring と take の違いが come と go の違いそのままだと分かると、迷いが消えます。

緑 = 基準や相手
オレンジ = 主役（動く側、変わる側）
破線 = まだそうでない、または見えない

まちがえやすい組み合わせ絵を並べると違いが一瞬でわかる
