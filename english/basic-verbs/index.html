基本動詞をイメージで理解する

get の正体はスイッチが 0 から 1 に切り替わること。骨組みを 1 枚の絵にして、63 の基本動詞と 45 の句動詞まで一気につなげる全 7 回

← 英語シリーズへ戻る

基本動詞は訳語が多すぎて辞書が引けません。get を「得る、なる、着く、分かる、させる」と並べても覚えられないのは当然です。実際には骨組みが 1 つだけあって、そこに入る材料が変わっているだけです。get なら「何かを経て、スイッチが 0 から 1 に切り替わる」。暗くなるのも、切符を手にするのも、駅に着くのも、全部この 1 枚で説明が届きます。このサブシリーズでは 63 語の骨組みを前置詞シリーズと同じ描き方の図で揃え、最後に句動詞を「動詞の絵 × 前置詞の絵」に分解します。

It got dark は「暗くない」から「暗い」へ。I got a ticket は「持っていない」から「持っている」へ。I got there は「いない」から「いる」へ。get him to help なら、相手のスイッチを入れることになります。切り替わる先が違うだけで、絵は 1 枚です。

01 ・ 10 枚

be と get — 状態と、その切り替え

be は＝で結ぶだけ、get は切り替える、become は切り替わりきる、turn は回る、grow は膨らむ、keep と stay は切り替えを止める。この対比が残り全部の下敷きになります。get cold と turn cold と grow cold の違いも図で。

 02 ・ 11 枚

have と take — 手の内に入れる

have は動かす動詞ではなく「自分の圏内にある」と言う動詞です。take が引き込み、give と send が外へ出し、put と set が位置を決め、hold が押さえ、leave が残して離れる。bring と take の違いは come と go の違いそのままです。

 03 ・ 10 枚

make と do — 行いと、生み出し

make him wait と get him to wait と have him wait と let him wait は、日本語ではどれも「待たせる」ですが力の入れ方が別物です。4 段階を図で並べ、work と run、try to と try -ing の違いまで整理します。

 04 ・ 10 枚

look と see — 目と耳と心の向き

look と see、listen と hear が分かれるのは、矢印の向きだけです。自分から向けるものには at や to が要り、入ってくるものには要りません。think は動かしている最中、know は固定済み。だから進行形にできるかが変わります。

 05 ・ 10 枚

say と tell — ことばを渡す四つの形

say は中身、tell は相手、speak は一方向、talk は往復。say me と言えないのに tell me と言える理由が、4 枚の絵で片づきます。show が見える形で届け、write が残し、read が取り込む対まで。

 06 ・ 12 枚

start と break — 始まり、終わり、手を加える

stop は途中で止まるだけ、finish は残りがゼロになる。break は境目がでたらめ、cut は自分で線を決める。rise と raise、fall と drop のように「自分で動くか、動かすか」で対になる語もここで。

 07 ・ 式 9 本と 125 語の一覧

句動詞は掛け算 — 動詞の絵 × 前置詞の絵

get up も put up with も熟語ではありません。動詞の骨組みと前置詞の絵を並べると意味が出てきます。9 本の式で組み立てを見せ、有名な句動詞 45 本を 2 枚の絵に分解し、基本動詞 125 語の骨組み一覧で抜けを確かめます。
