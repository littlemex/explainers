Engram と Attention の中身を、実際の値で 1 歩ずつ追う

結論から。Engram は表の中を探しません。トークンの番号から計算だけで 16 個の行番号を出し、その行を直接読みます。読んだ 16 行 × 64 個 = 1,024 個の数に学習した行列を掛けて key と value を作り、key を GPT 本体の隠れ状態と1 回だけ比べて、value を足す量を決めます。Attention は、現在地の q をそれまでの全位置の k と比べて重みを分け合い、多くの v を混ぜます。

このページの値。Zenn の記事「小さな GPT で Engram を試す」で作ったモデル（seed 1337）に、文「The girl was called Little Red Riding」を入れ、現在地「␣Riding」で計算の途中の数をすべて取り出したものです。手で計算し直したゲートは 0.887 で、モデルが記録した値と一致しました。

1. Engram: 番号で行を決め、読み、1 回だけ比べる

真ん中の柱が表です。左側で、トークンの番号から行番号を計算します。矢印は、16 個の行番号が柱のどの高さを指すかを示しています。右側で、読み出した 16 行が key と value に変わり、ゲートを掛けて足されるまでを示します。「次へ」を押すと、その段だけが濃くなります。

よくある誤解。key と value を作ってから表と照合する、のではありません。表を引くのは手順 5 だけで、それは番号の行をそのまま読む操作です。照合に当たる比べる計算は手順 8 の 1 回だけで、その相手は表ではなく、GPT 本体が計算している途中の隠れ状態です。

2. Attention: 全位置の k と比べて、重みを分け合う

同じ文で、GPT の各ブロックにある Attention を追います。Engram と同じく、比べて、掛けて、足す計算ですが、候補は文脈の全位置から作られ、重みは候補の間で分け合います。

4. このページで扱っていないこと

  • 値は seed 1337 の 1 か所、1 つの文のものです。ゲートや重みは位置と文で変わります。
  • Attention はブロック 1 の 1 つのヘッドだけを示しました。12 ブロック × 8 ヘッドのそれぞれが、別の重みの分け方をします。
  • 学習で表の行がどう書き換わるかは、ここでは追っていません。

値の取り出しは zenmai-lab の experiments/2026-10-21-engram-nanogpt（commit 7d12d41）の公開モデル（Hugging Face の littlemex/engram-nanogpt-wikitext103、revision e9758158）で行いました。行番号は NgramHash の出力と、ゲートはモデルが記録した値と、Attention は PyTorch の scaled_dot_product_attention と照合しています。
