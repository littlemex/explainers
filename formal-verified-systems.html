1. CompCert と seL4: コンパイラと OS カーネル

CompCert は C コンパイラで、公式サイトは「機械による数学的な証明によって、誤コンパイル (miscompilation) から免除されていることが形式的に検証されている」と説明しています。証明は Coq (Rocq) で書かれ、「生成された実行コードが、元の C プログラムの意味論の通りに振る舞うことが証明されている」とされます。ただし証明の範囲には注意が必要です。公式サイトによれば、証明の対象は主に CompCert の内部表現からアセンブリへの変換部分で、構文解析の一部や最終的なアセンブリ・リンクの段階は形式的には検証されていません。

seL4 は OS カーネルで、seL4 Foundation の FAQ は「コードレベルの完全な機能的正しさの証明を持つ、唯一の汎用 OS カーネル」と説明しています。さらに integrity (完全性) と confidentiality (機密性) というセキュリティ特性も証明されており、「セキュアであると証明された世界初 (かつ現在も唯一) の OS」とされます。証明支援系は Isabelle/HOL で、ARM v7/v8, x86, RISC-V に対応します。32 ビットの ARM (ARM v7) と 64 ビットの RISC-V では、「ハードウェア上で実行されるバイナリコードが C 実装の正しい変換である」ことまで証明が届いています。64 ビットの ARM v8 と x86 では、証明は C コードの機能的正しさまでで、ARM v8 のさらなる検証は進行中とされています。

図: CompCert の証明は変換の中心部分を覆うが、構文解析の一部や最終リンクは証明の対象外と公式サイトに明記されている。

2. AWS Cedar: 認可エンジンの検証と差分テスト

Cedar は AWS が公開している認可ポリシー言語です。cedar-spec リポジトリの Lean 形式化 (cedar-lean) では、次のような定理が証明されています。許可は明示的な permit ポリシーによってのみ得られる (エラーや既定で許可されることはない)、forbid ポリシーが 1 つでも当たれば必ず拒否される (forbid が permit を上書きする)、型検査器が受理した式は評価してもその型の値になるかエラーになるかのどちらかである (型検査の健全性)、そして記号的コンパイラの変換結果が本来の意味論を over-approximate (安全側に広く) かつ under-approximate (安全側に狭く) していること、の 4 つです。

ここで証明されているのは Lean で書かれたモデルについての性質で、実際に動いている Rust の実装そのものではありません。そこで Cedar チームは、同じ入力を Lean モデルと Rust の本番実装の両方に流し、出力が一致するかを大量に確認する差分ランダムテスト (DRT) を組み合わせています。モデルについての証明と、実装がモデルと一致することの大規模なテストを両方使うことで、最終的に動いているコードへの確信を積み上げる構成です。

3. s2n-bignum と Zelkova: 暗号とアクセス許可の自動推論

s2n-bignum は、AWS の TLS 実装で使われる暗号処理の低レベルなアセンブリ関数を集めたライブラリです。README によれば、各関数について「機械でチェックされた証明を通じて、オブジェクトファイルが高水準の数学的な仕様を、特定のテストケースだけでなく全入力について満たすこと」を HOL Light で証明しています。たとえば bignum_mul_p25519 という関数は、どんな入力でも (m * n) mod p_25519 という式の通りに計算することが証明されており、バッファが重なっていないことなどのメモリ安全性も証明の対象に含まれます。

Zelkova は、AWS のアクセス許可ポリシー (IAM や S3 バケットポリシーなど) を分析する社内ツールです。論文によれば、ポリシーを SMT (充足可能性モジュロ理論) の式に変換し、既製の SMT ソルバーと、Z3 を拡張した内製の Z3Automata を使って、「あるポリシーが別のポリシーより許可範囲が広いか」といった性質の妥当性を検証します。S3, AWS Config, Macie, Trusted Advisor, GuardDuty などで使われ、1 日に数百万回呼び出され、ポリシーに関する質問の 99% を 160 ミリ秒未満で答えられると論文は報告しています。SMT ソルバーが調べているのは、個別に試した入力ではなく、あり得るすべてのアクセス要求についての関係です。
