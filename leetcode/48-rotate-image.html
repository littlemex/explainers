48. Rotate Image

n×n の画像 (行列) を時計回りに 90 度回転させる。新しい行列を作らず、転置してから各行を左右反転するだけで済む。

Medium行列操作
← LeetCode 問題集の一覧へ LeetCode の原文を開く ↗

問題

画像を表す n x n の 2 次元行列 matrix が与えられます。画像を時計回りに 90 度回転させてください。

画像はインプレース (入力の 2 次元行列そのものを直接書き換えること) で回転させる必要があります。つまり、別の 2 次元行列を新しく確保して回転を行ってはいけません。

例

matrix = [[1,2,3],[4,5,6],[7,8,9]] → [[7,4,1],[8,5,2],[9,6,3]]
matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]] → [[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]

制約

  • n == matrix.length == matrix[i].length
  • 1 <= n <= 20
  • -1000 <= matrix[i][j] <= 1000

考え方

まっすぐ「90 度回転後の位置を計算して書き込む」方法を考えると、matrix[i][j] は回転後に matrix[j][n-1-i] の位置に行きます。これを直接行うと、元の値をどこかに覚えておかないと上書きしてしまうので、工夫が必要です。

そこで、90 度の回転を 2 つの簡単な操作の組み合わせに分解します。

  1. 転置 (行と列を入れ替える。matrix[i][j] と matrix[j][i] を交換する) をします。
  2. 各行を左右に反転します。

この 2 つを順番に行うと、ちょうど時計回りに 90 度回転した行列になります。どちらの操作も「2 つの要素を交換する」だけなので、追加の行列を作らずにインプレースで行えます。

なぜこれで回転になるのか実際に確かめてみましょう。[[1,2,3],[4,5,6],[7,8,9]] を転置すると [[1,4,7],[2,5,8],[3,6,9]] になり、各行を反転すると [[7,4,1],[8,5,2],[9,6,3]] になります。これは例 1 の答えと一致します。
転置で matrix[i][j] と matrix[j][i] を交換するループを j = 0 から回すと、同じペアを 2 回交換して元に戻してしまいます。j は i + 1 から始め、対角線より上側だけを 1 回ずつ交換します。

動くデモ

黄色が転置で交換している 2 マス、青が行反転で交換している 2 マスです。

解答 (C++)


class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {  //@transpose
                swap(matrix[i][j], matrix[j][i]);
            }
        }
        for (int i = 0; i < n; i++) {
            reverse(matrix[i].begin(), matrix[i].end());  //@reverse
        }
    }
};
時間計算量O(n²)。転置と行反転はどちらも全マスを定数回ずつ触るだけです。
空間計算量O(1)。交換だけで新しい行列は作りません。

よくある間違い

  • 転置のループを j = 0 から回し、同じ要素のペアを 2 回交換して転置が起きない。
  • 反時計回りと時計回りを混同する。反時計回りにしたいなら、転置の代わりに「各行を先に反転してから転置する」、または「反対の対角線で転置する」必要があります。
  • 新しい行列を作ってコピーしてから返してしまう。問題はインプレースでの変更を要求しています。

確認問題

Q1. 転置と行反転の順番を逆にする (先に反転、後で転置) とどうなりますか?

反時計回りに 90 度回転した行列になります。順番や軸を変えることで、4 方向の回転を同じ道具で作れます。

Q2. 180 度回転させたいときはどうしますか?

90 度回転を 2 回行うか、もっと簡単に「各行を反転してから、行の順番全体を上下反転する」でも同じ結果になります。
