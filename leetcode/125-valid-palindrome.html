125. Valid Palindrome

文字列から英数字以外を取り除き小文字にそろえたとき、前から読んでも後ろから読んでも同じかを判定する。両端から 1 文字ずつ指を動かして比べれば、新しい文字列を作らずに調べられる。

問題

ある文、または語句が回文 (前から読んでも後ろから読んでも同じになる文字列) であるとは、大文字をすべて小文字に変換し、英数字 (アルファベットと数字) 以外の文字をすべて取り除いたあとに、前から読んでも後ろから読んでも同じになることです。

文字列 s が与えられます。それが回文であれば true を、そうでなければ false を返してください。

制約

  • 1 <= s.length <= 2 * 10^5
  • s は印字可能な ASCII 文字だけで構成されます。

例

s = "A man, a plan, a canal: Panama" → true
"amanaplanacanalpanama" は回文です。
s = "race a car" → false
"raceacar" は回文ではありません。
s = " " → true
s は英数字以外の文字を取り除くと空文字列 "" になります。空文字列は前から読んでも後ろから読んでも同じなので、回文です。

考え方

まず思いつくのは、英数字だけを抜き出して小文字化した新しい文字列を作り、それを逆順にしたものと比べる方法です。これは正しく動きますが、新しい文字列を 2 つ作るので余分な記憶領域 (O(n)) を使います。

実は新しい文字列を作らなくても判定できます。元の文字列の両端から 1 文字ずつ指を動かし、それぞれ英数字でない文字はスキップし、残った文字どうしを小文字にして比べればよいのです。両方の指がすり合うまでこれを続け、最後まで一致していれば回文です。これが 2 ポインタ (配列や文字列の両端、または複数箇所から同時に動かす指) というテクニックです。

英数字かどうかの判定には isalnum (アルファベットか数字なら true を返す関数) が使えます。大文字小文字をそろえるには tolower を使います。
空文字列や、英数字が 1 つもない文字列 (例えば記号だけの文字列) は、取り除いたあとに長さ 0 になり、必ず回文として true になります。この境界条件を忘れて配列外参照を起こさないよう、ループの継続条件は常に lo < hi にします。

動くデモ

黄色が今比べている両端の文字、灰色のまま飛ばされた文字が英数字以外としてスキップされた文字、緑が一致、赤が不一致で判定が終わった位置です。

解答 (C++)


class Solution {
public:
    bool isPalindrome(string s) {
        int lo = 0, hi = (int)s.size() - 1;
        while (lo < hi) {  //@loop
            while (lo < hi && !isalnum((unsigned char)s[lo])) lo++;  //@skiplo
            while (lo < hi && !isalnum((unsigned char)s[hi])) hi--;  //@skiphi
            if (lo < hi) {
                if (tolower(s[lo]) != tolower(s[hi])) return false;  //@cmp
                lo++; hi--;  //@move
            }
        }
        return true;
    }
};
時間計算量O(n)。2 つの指はそれぞれ文字列を 1 回だけなめます。
空間計算量O(1)。新しい文字列を作らず、元の文字列の中だけで比較します。

よくある間違い

  • 英数字以外をスキップするループの条件に lo < hi を付けず、全部が記号の文字列などで配列外を読んでしまう。
  • tolower を比較の直前にかけ忘れ、大文字小文字が違うだけで不一致と判定してしまう。
  • 一致したあとに lo++, hi-- を忘れ、無限ループになる。
  • 「英数字以外を全部消した新しい文字列」を作ってから比較する方法自体は正しいが、O(n) の余分な記憶領域を使う点で 2 ポインタ解法より劣る。

確認問題

Q1. 英数字だけを抜き出した新しい文字列を作る方法と、2 ポインタで元の文字列を直接なめる方法では、どちらが優れていますか?

どちらも時間計算量は O(n) ですが、新しい文字列を作る方法は O(n) の追加の記憶領域を使います。2 ポインタ解法は O(1) の追加記憶領域で済むので、メモリの面で優れています。

Q2. 大文字・小文字を区別する (区別しない、ではなく区別する) 回文判定にするには、どこを直しますか?

tolower(s[lo]) != tolower(s[hi]) の比較から tolower を外し、s[lo] != s[hi] に変えるだけです。英数字以外をスキップする処理はそのままで構いません。

Q3. 文字を 1 文字だけ消してもよいなら回文にできるか (Valid Palindrome II) を判定するにはどう拡張しますか?

2 ポインタで最初に不一致が見つかったとき、lo を 1 つ進めた文字列と hi を 1 つ戻した文字列のどちらか一方を飛ばして、残りが回文になるかを再帰的に調べます (680. Valid Palindrome II)。
