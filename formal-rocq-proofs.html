この回の前提: 第 14 回 Rocq 入門: 型と関数

前回は Compute で計算させ、Example で小さな主張を確かめました。今回は Theorem というもっと本格的な主張の書き方と、証明の途中で ゴール (示すべき式) がどう変わっていくかを見ます。仮定の等式を使う rewrite と、場合分けする destruct という 2 つのタクティクが主役です。

1. ゴールの動き ― intros, simpl, reflexivity

Theorem は証明したい主張を書くキーワードです。すべての自然数 n について 0 + n = n が成り立つ、という主張を証明してみます。

Theorem plus_O_n : forall n : nat, 0 + n = n.
Proof.
  intros n. simpl. reflexivity.
Qed.

証明を始めた直後のゴールは forall n : nat, 0 + n = n という「すべての n について」の形をしています。intros n はこの n を具体的な (しかしまだ値の分からない) 1 つの対象として受け取り、ゴールを 0 + n = n に変えます。0 + n は、足し算が最初の引数で場合分けして定義されているため、最初の引数が具体的な 0 であればすぐに計算が進みます。simpl がこの計算を行い、ゴールは n = n になります。両辺が完全に同じ形になったので reflexivity が成功し、Qed で証明が確定します。

図: ゴールは intros → simpl → reflexivity と進むたびに形を変えていく。

2. rewrite ― 仮定の等式でゴールを書き換える

仮定に等式がある場合、rewrite というタクティクでゴールの中の該当する部分を置き換えられます。

Theorem plus_id_example : forall n m : nat,
  n = m -> n + n = m + m.
Proof.
  intros n m.
  intros H.
  rewrite -> H.
  reflexivity.
Qed.

intros n m で n, m を受け取ったあと、ゴールは n = m -> n + n = m + m という「ならば」の形になります。もう一度 intros H を行うと、前件 n = m が H という名前の仮定になり、ゴールは後件の n + n = m + m だけになります。rewrite -> H は、ゴールの中の n を H の左辺から右辺へ、つまり m に置き換えます。結果、ゴールは m + m = m + m となり、reflexivity で閉じます。

3. destruct ― 場合分けで突破する

ある命題を証明するには場合分けが必要になることがあります。destruct は、値がとりうる形で証明を複数のゴールに分けるタクティクです。

Theorem andb_commutative : forall b c : bool, andb b c = andb c b.
Proof.
  intros b c. destruct b eqn:Eb.
  - destruct c eqn:Ec.
    + reflexivity.
    + reflexivity.
  - destruct c eqn:Ec.
    + reflexivity.
    + reflexivity.
Qed.

destruct b eqn:Eb は、b が true の場合と false の場合の 2 つのゴールに分け、- (ハイフン) で区切ります。それぞれの中でさらに destruct c eqn:Ec を行い、+ (プラス) で区切った 4 つのゴールができます。4 通りの組合せのどれでも andb b c と andb c b は同じ値に計算できるため、すべて reflexivity で閉じます。Qed は、4 つのゴールすべてが実際に閉じたことを、タクティクの指示とは別に Rocq 自身がもう一度確かめたという意味を持ちます。

図: destruct を 2 段重ねると 4 つのゴールに分かれ、すべて reflexivity で閉じる。
