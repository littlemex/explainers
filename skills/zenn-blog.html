/zenn-blog

Zenn が記事の中に HTML と CSS を埋め込めるようになった。この skill は、記事の図を PNG の貼り付けではなく、その場で動き、部品を押すと初歩的な説明と出典が出る HTML にする。初歩的な説明を図に移すので、本文は主張と流れだけに絞れる。

要点

いつ打つZenn の blog や book の章を書くとき、既存の記事の図を作り直すとき
図の作り方```html-embed のブロックに HTML と CSS を書く。JavaScript は動かないので、切り替えも動きも CSS だけで作る。1 ブロック 50 KB、見える高さは 500 px まで
図の決まり背景は黒。右上に英語と日本語の切り替えを置き、既定は英語。色だけで役割を分けず、模様と形も変える。動きは控えたい人の設定で止まる
押して読む部品を押すと、下の欄に初歩的な説明、機能の概要、出典の URL が出る。本文から初歩的な説明を減らせる
Stopどの図にも右上に Stop を置く。押すと動きがすべて止まり、静止画として描くならこう描く、という完成した状態になる。動くと困る読者と、静止画として写したい読者のため
冒頭の案内記事の「はじめに」の後に、図は押すと基本の説明が出る、言語を切り替えられる、Stop で静止画になる、という全記事共通の文を置く (assets/template-blog.md)。基本の説明は本文に書かない
legacy静止画で足りる図は、これまでどおり pptx から PNG を作る (/pptx)
実装claudecode/.claude/skills/zenn-blog/SKILL.md、図の部品 assets/kit/ (core.py が枠と skin と Stop)、確認用の描画 assets/snap.py

図のスタイルを選ぶ

頼むときに「スタイルは stepper」のように ID を書くと、そのスタイルで作る。書かなければ、図の内容に合うものを選ぶ。下の見本は、Zenn と同じく JavaScript を切った状態で動いている。右上で言語を切り替え、部品を押して確かめられる。

map部品の全体像と、部品の間を何が流れるか。部品を押すと説明が出る。粒が流れる (見本: overview)
record1 つのものが、どの部品のどこに分かれて置かれるか。部分を押すと説明 (見本: records)
deal1 つの動きの繰り返しと、設定値による違い。設定値を切り替え、用語を押す (見本: striping)
stepper順番に進むやりとり。「次へ」「戻る」で 1 歩ずつ。Stop で全部の矢印と説明が並ぶ (見本: read_flow)
tree木構造と、その枝がどこに置かれるか。用語を押すと説明 (見本: dne)
stepper3 者のやりとり。stepper の 3 列版 (見本: locks)
stackソフトウェアやプロトコルの層。層を押すと説明。粒が上から下へ通る (見本: client_layers)
scenario場合によって順番が変わるやりとり。場合を切り替え、1 歩ずつ (見本: rpc_bulk)
anatomy1 つの名前や値の組み立て。部分を押すと説明 (見本: nid)
fanout1 つの層の下に、種類ごとの実装が並ぶ。粒が各実装へ (見本: lnet_lnd)
scenario2 者のやりとりを場合で切り替える (見本: messages)
chart値が時間とともに変わる様子。線が左から描かれ、Stop で描き終わった線になる (見本: health)
bridge2 つの領域を、間の部品が取り持つ。粒が端から端へ (見本: router)
states状態遷移と、場合による道筋の違い。場合を切り替えると粒がたどる道が変わる (見本: import_states)

見た目 (skin) を選ぶ

頼むときに「skin は excalidraw-sketch」のように書くと、その見た目で作る。書かなければ zenn-dark。zenn-dark 以外の 6 つは、review-html の figstyles (Hugging Face の skill の図の書式) を黒背景に合わせたもの。図は色を直接書かず役割で描くので、skin を替えても模様と形の区別は残る。

流れ

  1. 図ごとにスタイルを選び、押したら何を読ませるか (部品、初歩的な説明、出典) を先に書き出す。
  2. 見本の関数を写して中身を差し替え、HTML のブロックを作る。50 KB 以下かを確かめる。
  3. JavaScript を切った描画で、最初の状態と押したあとの状態を、広い幅と狭い幅で撮って目で確かめる。
  4. 図の中の文を、本文と一次資料に突き合わせてレビューする。英語と日本語の食い違いも見る。
  5. 本文の画像を HTML のブロックに置き換え、図に移した説明を本文から削る。

SVG の線を描く動きを点線や切り抜きのアニメーションで作ると、色が薄く描かれることがあった。線は、黒い覆いを縮めて見せる方法で描く。
