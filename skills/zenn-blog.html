Zenn が記事の中に HTML と CSS を埋め込めるようになった。この skill は、記事の図を PNG の貼り付けではなく、その場で動き、部品を押すと初歩的な説明と出典が出る HTML にする。初歩的な説明を図に移すので、本文は主張と流れだけに絞れる。

要点

いつ打つZenn の blog や book の章を書くとき、既存の記事の図を作り直すとき
図の作り方```html-embed のブロックに HTML と CSS を書く。JavaScript は動かないので、切り替えも動きも CSS だけで作る。1 ブロック 50 KB、見える高さは 500 px まで
図の決まり背景は黒。右上に英語と日本語の切り替えを置き、既定は英語。色だけで役割を分けず、模様と形も変える。動きは控えたい人の設定で止まる
押して読む部品を押すと、下の欄に初歩的な説明、機能の概要、出典の URL が出る。本文から初歩的な説明を減らせる
legacy静止画で足りる図は、これまでどおり pptx から PNG を作る (/pptx)
実装claudecode/.claude/skills/zenn-blog/SKILL.md、図の部品 assets/figure_kit.py、確認用の描画 assets/snap.py

図のスタイルを選ぶ

頼むときに「スタイルは stepper」のように ID を書くと、そのスタイルで作る。書かなければ、図の内容に合うものを選ぶ。下の見本は、Zenn と同じく JavaScript を切った状態で動いている。右上で言語を切り替え、部品を押して確かめられる。

map部品の全体像と、部品の間を何が流れるか。部品を押すと説明が出る。粒が流れる
deal1 つの動きの繰り返しと、設定値による違い。設定値を切り替え、用語を押す
stepper順番に進むやりとり。「次へ」「戻る」で 1 歩ずつ進み、今の矢印が光る
stackソフトウェアやプロトコルの層。層を押すと説明。粒が上から下へ通る
chart値が時間とともに変わる様子。線が左から描かれ、ラベルを押すと説明が出る
states状態遷移と、場合による道筋の違い。場合を切り替えると粒がたどる道が変わる

流れ

  1. 図ごとにスタイルを選び、押したら何を読ませるか (部品、初歩的な説明、出典) を先に書き出す。
  2. 見本の関数を写して中身を差し替え、HTML のブロックを作る。50 KB 以下かを確かめる。
  3. JavaScript を切った描画で、最初の状態と押したあとの状態を、広い幅と狭い幅で撮って目で確かめる。
  4. 図の中の文を、本文と一次資料に突き合わせてレビューする。英語と日本語の食い違いも見る。
  5. 本文の画像を HTML のブロックに置き換え、図に移した説明を本文から削る。

SVG の線を描く動きを点線や切り抜きのアニメーションで作ると、色が薄く描かれることがあった。線は、黒い覆いを縮めて見せる方法で描く。
