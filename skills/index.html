skills シリーズ

自分で作った Claude Code のスキル (スラッシュコマンド) を、いつ・何のために打つのか思い出すためのカタログ

← explainers トップへ戻る

スキルが増えるとどのコマンドが何だったか覚えていられません。このシリーズは、各スキルを「発火条件・入出力・実行例」の 1 枚に落として一覧できるようにする索引です。スキルの実体 (手順そのもの) はリポジトリの SKILL.md にあり、ここはあくまで人間が思い出すためのリファレンスです。

三層の分け方 ― 手順そのものはスキル (SKILL.md)、手法カタログや判断基準など陳腐化しやすい知識は解説記事、コンペやプロジェクト固有の事実はその案件の CLAUDE.md に置く、という住み分けで運用します。
コーディング ・ サブシリーズ

coding スキル群

公開リポジトリやリファレンス実装への変更を、設計監査 → contract → 実装 (テスト実装者とコード実装者を分離) → 実装監査 → 実機検証の 5 フェーズで通すスキル群。レビューの発散と収束を別の作業として扱い、見つけた指摘の全部に手をつけないための contract を中核に置く。欠陥の分類 15 種をレビューのレンズとして収録し、GPU 学習スタック向けのドメインレンズ ml-infra-review を同梱。

 メタ ・ skill を育てる

/skill-curate

得た知見を「どの skill に入れるか」三層モデル (手順 / 知識 / 案件固有) で振り分け、正しいファイルに実際に反映するメタスキル。知見が消えたり間違った場所に積まれたりするのを防ぐ。Kaggle の学びを対応するサブコマンドへ流し込むのが典型。

 Kaggle ・ サブシリーズ

Kaggle スキル群

コンペに参加してから振り返るまでのワークフローを、段階ごとのスラッシュコマンドに切り出したスキル群。ルールを戦略 brief に変換する brief、対戦エージェント型の評価ハーネスを組む sim-agent、CV 設計と CV-LB 追跡の validation などを収録。API 操作は既存の nvidia-kaggle に任せ、その上の思考と規律を担う。

 資料作成 ・ ネイティブ pptx

/pptx

スライドを PNG で貼るのをやめ、コーポレートテンプレを適用した編集可能なネイティブ shape で組むスキル。テンプレから配色・フォント・余白を自動抽出し、ブロックを積むだけで高さが決まり、下端を越えたら例外で落ちる。draw.io で作るべき図とネイティブで作るべき図の線引きも収録。
