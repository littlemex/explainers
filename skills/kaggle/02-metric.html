/kaggle metric

指標をローカルに再実装して検算する

段階: 問題理解類型: 全優先度: 6
← Kaggle スキル群へ戻る
ドラフト ― このページは現時点で分かっている情報から書いた暫定版です。スキルの実体 (.claude/skills/kaggle/SKILL.md) はサブコマンドの仕様を定義済みですが、手順の細部は実装時に変わる可能性があります。

コンペの指標を自前で再実装し、sample submission で公式スコアと一致するか検算する。閾値・ランク平均・キャリブレーションといった事後処理で稼げる余地を先に洗い出す。

要点

発火条件brief の直後。指標が自明でない、または事後処理が効きそうなとき。
前提BRIEF.md に指標の数式が記録済みであること。公式 evaluation テキストの取得は nvidia-kaggle に任せる。
入力コンペ slug、sample submission。
出力指標のローカル実装 + 検算スクリプト + 事後処理の余地メモ。

やること

  • 公式 evaluation を nvidia-kaggle で取得し、指標を自前実装する。
  • sample submission で公式スコアと一致するか検算し、実装のズレを潰す。
  • 閾値最適化・ランク平均・確率キャリブレーションなど、モデルを変えずに稼げる事後処理の余地を分析する。

実行例

# 指標を再実装して検算
/kaggle metric <slug>

# → metric.py + 検算結果 + 事後処理メモ (抜粋)
公式との一致  : OK (sample で誤差 < 1e-9)
事後処理の余地: 閾値 0.50 → 0.42 で CV +0.003 (要 validation で確認)

境界と実体

生データの取得と提出そのものは既存の nvidia-kaggle スキルが担当し、このスキルはその情報を戦略・検証・規律に変換する層に徹する。API 呼び出しは再実装しない。

スキルの実体 (手順の正本): リポジトリの .claude/skills/kaggle/SKILL.md。このページは索引であり、手順の詳細は複製しない。
