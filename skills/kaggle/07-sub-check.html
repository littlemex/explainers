やること

  • 提出形式・index の整合・null を機械チェックする。
  • Code competition はネット遮断前提でオフライン dry-run し、実行時間を見積もる (時間超過で 0 点になる事故を防ぐ)。
  • 最終提出は「安全な CV ベスト」と「攻めた一手」の 2 本を保険的に選ぶ戦略も検討する (Home Credit)。
  • すべて合格した後に nvidia-kaggle の submit を呼ぶ。submit は 1 日枠を消費する外部可視アクションなので必ずユーザー確認を取る。
