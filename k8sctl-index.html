Kubernetes を拡張して自分の API を作るための連載です。各回は図を中心にした解説と、5 択 6 問のクイズでできています。細かいコードやテンプレートではなく、何がどこで何をしているかに絞り、必要な書き方だけを短く載せています。例に使う実験用の CRD は EKS 1.35 のテスト用クラスタで実際に動かし、その出力を載せています。最後の 3 回では、distributed-ai と Zenn の本「eks-distributed-ai」の課題から題材を選び、既存の FSx を namespace ごとに配るコントローラーを設計・実装し、FSx for Lustre と FSx for OpenZFS で確かめます。上から順に読むと、前の回の知識で次の回が読めるように並べてあります。
