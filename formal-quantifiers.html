この回の前提: 第 03 回 命題論理

前回、命題論理で「かつ」「または」「ならば」「でない」を正確に定義しました。今回はそこに「すべての」「ある」という言葉を加えます。これらは量化子 (quantifier) と呼ばれ、1 つの命題について話すだけでは足りない、集合全体についての主張を表すために使います。

1. すべて (∀) とある (∃)

∀x, P(x) (全称量化子, universal quantifier) は「どんな x についても P(x) が成り立つ」ことを表します。たとえば「∀n, n + 0 = n」は「どんな自然数 n についても、n + 0 は n に等しい」という意味です。この主張を崩すには、成り立たない x を 1 つ見つければ十分です。

∃x, P(x) (存在量化子, existential quantifier) は「ある x が存在して P(x) が成り立つ」ことを表します。たとえば「∃n, n > 100」は「100 より大きい自然数 n が存在する」という意味です。この主張を証明するには、実際に当てはまる具体的な値を 1 つ示せば十分です。Software Foundations の Logic の章では、この具体的な値のことを証拠 (witness) と呼び、たとえば「∃n, n = 4 + 3」を示すには、witness として 7 を 1 つ示すだけでよいと説明されています。

つまり ∀ は「全部調べて初めて成立が確認でき、1 つの反例で崩れる」、∃ は「1 つ見つけただけで成立が確認でき、全部確かめて初めて不成立が確認できる」という、互いに正反対の性質を持っています。この x が動く範囲のことを域 (domain) と呼びます。域が有限であれば、理論上はすべての x を 1 つずつ確認すれば ∀ も確認できますが、域が自然数全体のように無限であれば、それは不可能です。無限の域に対しても ∀ を確認する方法が、第 2 部以降で学ぶモデル検査や証明の出番になります。

2. 否定するとひっくり返る

∀ を否定すると ∃ に、∃ を否定すると ∀ に入れ替わります。「¬(∀x, P(x))」(すべての x で P(x) が成り立つ、わけではない) は「∃x, ¬P(x)」(P(x) が成り立たない x が少なくとも 1 つ存在する) と同じ意味です。逆に「¬(∃x, P(x))」(P(x) が成り立つ x が存在する、わけではない) は「∀x, ¬P(x)」(どんな x でも P(x) は成り立たない) と同じ意味です。

この逆方向、つまり「∀x, P(x) ならば ¬∃x, ¬P(x) である」という事実は、Software Foundations の Logic の章にも dist_not_exists という練習問題として登場します。「すべての x で P が成り立つ」ならば「P が成り立たない x は存在しない」、という日本語でもそのまま納得できる関係です。

具体例で確認してみましょう。「クラスの全員がテストに合格した、わけではない」は「合格しなかった生徒が少なくとも 1 人いる」と同じ意味です。「合格しなかった生徒がいる、わけではない」は「全員が合格した」と同じ意味です。日本語の言い回しとしても、この入れ替わりは自然に感じられるはずです。

この入れ替わりは、前回学んだド・モルガンの法則の、量化子版だと考えることもできます。∧ の否定が ∨ になり、否定が両方の項に配られたのと同じように、∀ の否定は ∃ になり、否定が述語 P の方に配られます。命題論理で学んだ道具が、量化子を含む主張にもそのまま通用する、という点が見えてくるはずです。

3. 順序を変えると意味が変わる、反例 1 つで ∀ は崩れる

2 つの量化子を並べるとき、順序を入れ替えると意味がまったく変わることがあります。「∀x∃y, P(x,y)」(どの x に対しても、それぞれ別の y があってよい) と「∃y∀x, P(x,y)」(すべての x に共通して使える、ただ 1 つの y が存在する) は違う主張です。

例: 「どの人にも、その人より年上の人がいる」は ∀x∃y の形で、人によって「年上の人」が違ってもよいので成り立つかもしれません。しかし「ある 1 人がいて、その人はすべての人より年上である」は ∃y∀x の形で、同じ y (同じ 1 人) をすべての x (すべての人) に対して使い回さなければならず、一般には成り立ちません。∀x∃y は ∃y∀x より緩い (成り立ちやすい) 主張です。実際、∃y∀x, P(x,y) が成り立てば、その y をそのまま使うことで ∀x∃y, P(x,y) も成り立つことが示せます。つまり ∃y∀x から ∀x∃y は常に導けますが、逆は一般には成り立たないという、一方通行の関係になっています。

最後に、第 1 回で見たテストと証明の関係が、ここでも顔を出します。「∀x, P(x)」という主張全体を証明するには、本当にすべての x を調べ尽くす必要があります。しかし、この主張が成り立たないことを示すのは簡単で、P(x) が成り立たない x をたった 1 つ見つければ十分です。たとえば「すべての素数は奇数である」という主張は、2 という反例が 1 つあるだけで崩れます。この「反例 1 つで崩れる」という性質は、後の回で学ぶモデル検査が「成り立たないこと」を示すのを得意とする理由につながっています。

図: ∀x∃y は x ごとに別の y を選んでよいので緩い。∃y∀x は 1 つの y を全員に使い回すので厳しい。
